# 給別人用的下載說明（賽爾對戰模擬器）

## 需求

- Git for Windows：https://git-scm.com/download/win
- Node.js 20 以上 LTS：https://nodejs.org/

## 方法一：一鍵工具（推薦）

1. 把 `賽爾模擬器一鍵工具.bat` 跟專案放在一起，或第一次先隨便找個空資料夾放它。
2. 雙擊 → 選 `[1]`：
   - 如果是空資料夾，它會問倉庫網址，直接 Enter 用預設值，就會 `clone` 下來。
   - 如果已經是專案目錄，它會自動 `git pull`。
3. 接著它會自動跑 `npm install` + `npm run build`。
4. 選 `[4]` 啟動遊戲，瀏覽器開 `http://localhost:3000`。

## 方法二：手動指令

全新下載：

```powershell
git clone https://github.com/wa0966766851-ship-it/new-chat.git
cd new-chat
npm install
npm run build
npm run start
```

之後更新：

```powershell
cd new-chat
git pull origin main
npm install
npm run build
npm run start
```

跑測試驗證：

```powershell
npm run lint
npm test
```

打包自己發：

```powershell
npm run package:zip
```

產物在 `release/seer-battle-simulator-portable.zip`。

# Private 倉庫與協作者：先教會你

## 一、先確認倉庫現在是公開還是私人

1. 瀏覽器開 https://github.com/wa0966766851-ship-it/new-chat
2. 看倉庫名稱旁邊有沒有 `Private` 徽章：
   - 有 = 私人，只有你和你加的人能看能拉。
   - 沒有 = 公開，任何人都能 `git clone`，但只有你能 `push`。

## 二、想給特定的人看、能拉不能推（推薦做法）

1. 進倉庫頁 → 上方 `Settings` → 左側 `Collaborators`（或 `Access` → `Collaborators`）。
2. 按 `Add people`，輸入對方的 GitHub 帳號，寄邀請。
3. 權限選 `Read`（只能拉、不能推）或 `Triage`，不要一開始就給 `Write`。
4. 對方接受邀請後，用一般 HTTPS 就能 clone：

```powershell
git clone https://github.com/wa0966766851-ship-it/new-chat.git
```

第一次會跳 GitHub 登入（瀏覽器或 Personal Access Token），登入一次就行。

## 三、想給對方也能推（共同開發）

1. 同一個 `Collaborators` 頁，權限改成 `Write`。
2. 對方流程跟你一樣：

```powershell
git pull origin main
REM 改完先驗證
npm run lint
npm test
git add -A
git commit -m "說明改了什麼"
git push origin main
```

3. 建議約定：每次 push 前先 `npm test` 全綠，不然 Codex 雲端會紅燈。

## 四、想完全公開（任何人免登入下載）

1. 倉庫頁 → `Settings` → 拉到最下面 `Danger Zone` → `Change repository visibility` → `Make public`。
2. 之後任何人免登入就能：

```powershell
git clone https://github.com/wa0966766851-ship-it/new-chat.git
```

3. 注意：公開後程式碼全世界可見，`.env`、`GEMINI_API_KEY` 這類絕對不能進倉庫（專案 `.gitignore` 已經擋掉 `.env*`，不要手動 `git add -f` 去加回來）。

## 五、Private 倉庫別人 clone 失敗怎麼辦

常見三種：

1. `404 Not Found`：對方沒權限或沒登入。先確認你有加他為 collaborator，且他已接受邀請。
2. `Authentication failed`：HTTPS 憑證過期。叫他用 GitHub 官網重新登入一次，或改用 SSH key。
3. `fetch_content` 抓首頁 404：跟上面同一件事，private 倉庫未登入視角本來就看不到，`git ls-remote` 通就代表倉庫存在，不用理會。

## 六、你之後的更新流程（固定三步）

```powershell
npm run lint
npm test
npm run build
git add -A
git commit -m "說明這次改了什麼"
git push origin main
```

Codex 雲端那邊按 Sync 就會跟上。
