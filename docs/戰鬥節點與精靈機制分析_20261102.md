### 關鍵結論：節點數 ≠ 強度

- **九青**：14 個節點（最多），但上一輪 100 場測試勝率僅 36.4%
- **無序·六刃**：只有 5 個節點，勝率卻有 65.2%

**節點多只代表「觸發點多」，不代表每個觸發點都有足夠強的數值。**

## 四、四隻「逆天」精靈的機制拆解

### 1. 無序·六刃（5022）— 傷害倍率疊乘

**魂印原文：**
```
常駐效果：
> 自身恢復體力無法恢復/增加超過至自身原始體力上限
> 自身造成非真實傷害提升120%
>> 自身體力每降低0.1%，上述效果提升120%，體力低於最大體力½時效果翻倍
> 自身每次受到真實傷害時
>> 2回合內抵擋受到的所有技能傷害且受到的固定傷害、百分比傷害不超過60
> 自身每次使用技能時，恢復自身最大體力⅙並造成等量百分比傷害
```

**節點：** 1.3, 2.2, 3.2, 3.5, 3.7（只有 5 個）

**逆天點：**
- 「體力每降低 0.1% → 效果 +120%」是**乘法疊乘**，不是加法
- 血量 50% 時效果翻倍，配合「每次使用技能恢復 1/6」形成**自循環**
- 實測可打出 **-62580** 的傷害（對手僅 894 血）

**弱點：** 需要先掉血才能爆發，開局是白板。

---

### 2. 異境神霆·雷伊（5029）— 神降負血

**魂印／特質：**
```
survival_rule: mode='god_descent', floorMult=70
體力下限 = -70 × 當前最大體力
自身每次受到非真實傷害時免疫此傷害，改為扣除自身體力上限70%的體力值
```

**節點：** 三個死亡節點全掛（3.10, 4.11, 5.4）

**逆天點：**
- 894 血的雷伊，**等效血量 = 894 + 62580 = 63474**
- 非真實傷害完全免疫，只扣 70% 上限
- 上限變動時下限自動重算（2026-11-02 修正）

**弱點：** 真實傷害正常結算，且到達下限即死亡。

---

### 3. 鎮魂·巴弗洛（5008）— 魂殤無視抗性

**魂印原文：**
```
若自身存活於出戰背包內或在場：
> 每回合開始時為敵方在場精靈附加1道魂殤
魂殤：
> 持有者回合結束時，每有1道令自身體力調整減少最大體力25%
> 上限4道，下場後消失
```

**節點：** 2.1（回合開始）＋ 5（回合結束）

**逆天點：**
- **在背包裡就能生效**（不需要上場）
- 4 回合內必死（4 × 25% = 100%）
- 「體力調整」不是傷害，**無視護盾、抗性、減傷**

**弱點：** 換人可清空魂殤。

---

### 4. 岳峙淵渟·卡修斯（5041）— 超額傷害攔截

**teamRules：**
```ts
{ shieldDeductionRatio: 0.5, excessIntercept: true, excessTrueRebirth: true }
```

**逆天點：**
- 護盾扣減減半（等效容量 ×2）
- 超額非真實傷害 > 護盾 → **本次傷害完全無法造成**
- 超額真實傷害且致死 → **100% 重生（無次數限制）**

**弱點：** 護盾歸零後全部失效。

## 五、節點分析對「怎麼玩」的啟示

### 1. 速度是第一個決策點

**2.2 先手判定有 44 隻精靈參與。** 速度快的精靈（帝皇之盾 504、鎮魂·巴弗洛 504）能搶到先手，先手方在 3.2 先結算。

### 2. 換人是核心戰術

**1.3 登場時有 29 隻精靈掛效果。** 換人不只是躲傷害，還能觸發大量登場效果。

**同時：** 鎮魂·巴弗洛的魂殤「下場後消失」，換人是最直接的反制。

### 3. 傷害類型決定用什麼防禦

| 攻擊類型 | 應對 |
|---|---|
| SKILL-FULL（一般攻擊） | 護盾、減傷、抵擋 |
| FIXED（固定傷害） | 抗性、護罩 |
| PERCENT（百分比） | 抗性、護罩 |
| TRUE（真實傷害） | **只能靠體力與存活規則** |

### 4. 三階段死亡節點意味著「死了還有事」

**19 隻精靈在 3.10、4.11、5.4 都有掛效果。** 擊殺一隻精靈後，它的死亡效果還會依序觸發三次。
