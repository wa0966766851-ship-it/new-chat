# 手動更新、Electron 瘦身與本輪交付

## 已實裝（未推送、未發布 Release 或網站）

- 管理中心新增「檢查更新」分類。網頁端與原更新提示共用檢查狀態，避免不同判斷及重複請求。
- 網頁端檢查已部署的版本，不清本機資料；戰鬥／編輯中不能套用重載，回首頁確認後才載入。
- 正式建置提供 version、commit、buildId、builtAt。同一基底提交重新建置也能辨識；本機髒工作樹的 commit 是基底提交，不代表全部更動已提交 GitHub。
- Electron 僅用隔離的更新 IPC 查詢固定 GitHub 倉庫的正式 Release，不允許前端任意檔案路徑或命令。
- 有 SHA-256、版本及正確檔名的 Windows x64 版本才能下載；限制 GitHub／其附件 CDN 來源、大小、重導向及逾時。
- 先寫入並讀回玩家備份；免安裝版另複製舊 EXE 並核對 hash，才下載新檔。下載用獨立暫存檔，核對成功後另存，取消或失敗不覆寫舊程式。
- 不自動執行或安裝新版，不清存檔。安裝版並未實裝整包自動回滾。
- 原素材不修改。封裝副本只刪同 bytes 且已有可用路由副本的重複檔；本輪去重 440 檔／37,949,790 bytes，保留 JSON 索引。
- Electron 語言包只留 en-US、zh-CN、zh-TW；三份 EXE 的聖靈譜尼圖標逐幀核對通過。

## 按需素材試驗版

`scripts/prepare_light_assets.mjs` 只建立新的 build 副本，正式版及原圖不動。產生版本釘選的 asset-manifest，附件用 SHA-256 命名；伺服器下載後驗證、保存快取，最多 3 筆同時下載，失敗不把錯檔當正確素材。快取命中可離線重用；首次未下載仍須連線。

副本：`build/electron-lite-20261004`；其中 `release-assets` 是未發布附件。本輪首頁／版本／無金鑰 API 啟動通過，沒有驗收 GitHub 真實下載全部素材及全部精靈畫面。正式與試驗 EXE 現在同名、分開目錄保存；正式發布前需制定不衝突的輕量版檔名及更新通道，不能混傳同名 Release 附件。
