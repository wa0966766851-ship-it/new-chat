# 共同機制與實裝修復計畫（2026-10-04）

本文件接手使用者提供的未實裝／替代實裝稽核。既有工作樹有其他未提交修改，保留，不重置、不整批提交。
狀態為「待修」者不等於已驗證；解析率、handler 存在、隨機對戰不崩潰都不是語意驗收。

## 使用者確認的規則

- 攻擊傷害是技能傷害的分支；其他技能傷害、固定、百分比、真實及體力調整分開。
- 吸取固定值體力＝固定傷害；吸取百分比／分數體力＝百分比傷害；汲取體力＝真實傷害。
- 吸血依指定傷害的結算值恢復，不以對手剩餘體力或實際扣血限制。恢復請求與實際恢復另行記錄。
- 「攻擊傷害提升100%並恢復等量體力」只涵蓋攻擊傷害，不含額外行動或其他附加技能傷害。
- 「下次」可在當次後续符合條件的節點觸發，不能追溯已通過的判定節點。
- 連擊：一次公式結算、一次傷害動畫；每擊附帶機率判定與傷害結算不是同一件事。
- 額外行動：獨立結算／演出節點，不叫連擊。六刃沿用使用者指定的多邏輯節點、單次演出特例，不改為六次動畫。
- 演出不显示「吸取／汲取」标签；技能傷害紅色，固定／百分比體力淨減少粉色，真實傷害白色；同收尾節點的粉／綠／白字同步展示，不改戰鬥結算次序。
- 奧佩婭：使用者確認包含體力的六維（體力、攻擊、防禦、特攻、特防、速度），六維總和×n×10%作為每一維的相同臨時加成；不是各項各乘百分比，更不是平均分配。
- 雷伊異能值保持無效果佔位；靈光之怒沿用現行公式。
- 蟲群庇護「若對手不處於全屬性能力下降狀態則下2回合內無法主動切換精靈」受限者為對手（2026-10-04使用者明確確認）。
