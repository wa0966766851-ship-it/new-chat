## 三、核心發現：幻化是「疊加」，不是「複製」

### 星核寰宇·艾斯菲亞 的「寰宇星幻」

**原文：**
```
出戰時執行寰宇星幻：
> 為該精靈附加所有星附屬類異常（默認各3回合）且幻化為對方在場精靈
```

**實測（星核 vs 六刃）：**

| 屬性 | 星核自身 | + 六刃 | = 幻化後 |
|---|---|---|---|
| **maxHp** | 1006 | 968 | **1974** |
| **atk** | 383 | 671 | **1054** |
| **spatk** | 635 | 383 | **975** |
| **def** | 456 | 410 | **866** |
| **spdef** | 456 | 410 | **866** |
| **speed** | 431 | 428 | **859** |

**關鍵：能力值是「自身 + 目標」相加，不是替換。**

### 技能也完全轉化

```
[0] 星核脈衝   → 狂刃無生 (power=66)
[1] 星霧迷境   → 靜刃止水 (power=66)
[2] 星核幻舞   → 蟄刃復歸 (power=66)
[3] 殞星衝擊   → 六刃碎界斷 (power=66)
[4] 寰宇幻影閃 → 終焉·六花斬 (power=666)   ← 第五技能
```

**幻化後可以使用對手的全部技能，包含第五技能。**

## 四、為什麼配裝貳能贏

### 對比配裝壹（輸給 AI-強攻隊）

**配裝壹沒有幻化精靈：**
```
雷伊、混濁海妖、鎮魂巴弗洛、誑獅魔軀、聖靈譜尼、無序六刃
```

**面對 AI-強攻隊（六刃×2 + 巴弗洛×2 的極端爆發配置），被倍率疊乘打死（3:8）。**

### 配裝貳的三層防禦

| 層級 | 精靈 | 機制 |
|---|---|---|
| **第 1 層：幻化** | 星核 | 變成對手 → 血量/能力疊加 + 用對手招式 |
| **第 2 層：反制** | 星軌 | 思維干涉（反彈100%）、空間跳躍（抵擋） |
| **第 3 層：控場** | 哈莫 | 龍神·御天陣（技能無效 + PP 戰） |

**三隻都不怕被秒，而且都能「越打越強」。**

## 五、幻化機制的完整拆解

### 星核「寰宇星幻」

```
出戰時：
> 為自身附加所有星附屬類異常（各3回合）
> 幻化為對方在場精靈

先出手 → 空間躍遷：
  對手攻擊技能無法造成技能傷害且附加效果失效
  觸發成功則該技能 PP 歸 0 + 自身體力恢復至 1/1

後出手 → 當回合受到非真實傷害減半
  + 回合結束吸取對方最大體力½

每次執行上述效果：
> 吸取對方在場精靈所有鄰位精靈的所有技能 1 點 PP，恢復至自身
> 若吸取令目標 PP 歸 0 → 下回合對手無法主動切換
> 同時將對方與目標精靈相同位數的技能 PP 扣減至 0
```

**這是「先手無敵」機制：先出手時對手的攻擊完全無效。**

### 星軌「思維固化」

```
每次登場執行思維固化：
> 若自身初始位於出戰背包 → 幻化為己方初始待命背包中對應位數的精靈
> 若自身初始位於待命背包 → 幻化為己方初始出戰背包中對應位數的精靈
> 解除條件：受 5 次技能伤害 + 5 次固伤 + 5 次百分比 + 5 次真伤 + 5 次异常 + 登场>5次
> 未满足前所有技能 PP +10 临时上限

先出手 → 思維干涉：
  自身受到的技能伤害减半 + 以真实伤害反弹 100% 给对手

後出手 → 空間跳躍：
  抵挡当回合受到的技能伤害 + 下回合对手先制-2

每次执行额外吸取对手最大体力⅓
```

**這是「反制」機制：反彈 + 抵擋 + 吸血。**

## 七、發現的異常

### 1. 存活數 > 6

```
T1 存活7 vs 存活7
```

**`checkElfDead` 把額外精靈（炫彩山神等）也算進去了。**

**測試統計應該排除 `isExtra`。**

### 2. hp = NaN

```
T4 星核 hp=NaN/17346
【星軌】體力調整（NaN）
```

**某個計算產生了 NaN，需要追查。**

### 3. maxHp 17346 異常

**星核幻化後 maxHp = 1974，但實戰顯示 17346。**

**差距 9 倍，可能是臨時上限疊加或某個效果重複觸發。**

## 八、結論

### 配裝貳為什麼是最強陣容

1. **幻化＝疊加**：星核/星軌變成對手/隊友時，能力值相加而不是替換
2. **先手無敵**：星核先出手時對手的攻擊完全無效
3. **反制能力**：星軌反彈 100% 傷害 + 抵擋
4. **PP 戰**：三隻都消耗對手 PP，拖到後期對手無招可用
5. **耐久**：三場都是 51 回合判定，靠存活數贏

### 配陣原則

| 原則 | 說明 |
|---|---|
| **帶幻化精靈** | 星核/星軌能把對手強度「借」過來 |
| **避免單一核心** | 配裝參只有冰魄柯爾德開局，容易被針對 |
| **平衡爆發與耐久** | 純爆發（配裝壹）怕被更強爆發打；純耐久（配裝貳）能磨贏 |
| **PP 戰是後期關鍵** | 51 回合判定時，PP 耗盡的一方會崩潰 |
