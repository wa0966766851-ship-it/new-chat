# 自製出招動畫、未知立繪與圖片重試

日期：2026-11-04。範圍為本機專案；未更新網站、桌面獨立發行目錄或 EXE。

## 玩家看到的變化

- 墜星先向上開炮，再從對手上方落下藍白砲擊；光效跨場地，不再受自己的角色圖塊裁切。
- 蝕言以額外行動的紫色咒陣為重點；普通攻擊降低光效強度。
- 帝辛使用金色斬擊；六刃使用黑色刀身與綠色邊緣。
- 缺少或載入失敗的全身圖使用完整未知精靈立繪，頭像用相應頭像。隱匿對象只載未知圖，不載其真實動作素材。
- 未知精靈的物攻、特攻、屬性、第五與額外行動使用同一套中性演出，避免從特效推測身分。
- 設定 → 對戰 → 動畫播放內新增「圖片載入失敗時」：自動重試／手動重試／不重試。預設自動，失敗後約八秒再試；手動直接點備用圖片；不重試則保持備用圖。一般畫面不增加常駐重試按鈕。

## 真正修掉的播放問題

切換片段時，舊待機片段會發送取消事件。原程式把事件一律改名為新要求的 extra／ultimate，導致新額外行動被誤認為已取消。現在只映射屬於實際播放片段的事件，保留舊片段的名稱。正式對戰已測蝕言左右兩側的額外行動，能播放、結算並返回選招。

圖片失敗紀錄除了有期限，也需要喚醒畫面重畫；只讓失敗記錄過期仍可能一直停在備用圖。現在有重試計時與設定連動，索引載入失敗也會釋放失敗的請求，允許下一次載入。
