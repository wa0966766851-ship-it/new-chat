## 物攻位移判定

以 attack 序列第一幀到最後一幀的水平邊界差判定，不是看檔名：

- rey70（普通雷伊）：位移非 0，既有設定 approach，維持。
- zhakesi15010（恐懼的化身·咤克斯）：位移非 0 但使用者已確認留在原地，維持 stationary。
- 其餘全部位移為 0，登記為 stationary（原地出招）。

位移為 0 不代表不能接動畫，只代表不需要額外的接近位移；實際播放仍讀 clip 自己的影格。
