# 六刃零體力規則修正

使用者確認：體力不受限制效果期間，體力最低0。零體力仍受到傷害，但傷害不能再影響體力；不以體力0判定死亡。雷伊神降可負體力是另一套規則，不可混用。

根因：`src/battle/survivalRules.ts` 的 `freeze_at_zero` 分支被2026-11-04的修改改成首次跨0保留負數，之後保留該負數；原有兩組測試仍要求0，因此並非正式設計要求負血。這次恢復共用規則的0下限，`ignoredDamage` 為false，避免把不扣體力當傷害免疫。實際體力損失仍為0，原始傷害交由既有receipt與跳字記錄，不把傷害偽造為體力損失。

修改限於共用生存規則、積木註解與回歸斷言；不在主引擎新增六刃名稱判定。舊戰場若已是-408，下次進入傷害結算時歸0；不代表正在運作的舊桌面程序會即時套用新程式。

已通過：battleAnimation.semantic、otherworldRey.semantic（15/15）、attackDefense.semantic（含48個雙側真實引擎情境）。型別與動畫引擎整合測試結果以本次工具輸出為準。未重新部署桌面或網站。

動畫品質另案：使用者指出整圖晃動及拆分不自然，本次數值修正不能當作該美術問題已解決。既有自製動畫像素歸屬／播放測試只能證明資料與接線，不能證明肢體動作自然或可比原廠動畫。
