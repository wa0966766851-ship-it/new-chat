## 為什麼資產用 ASCII 名

releaseClient 的匹配是 `name.endsWith(`-${version}-portable.exe`)`，
與中文前綴無關；ASCII 名同時避開 curl/URL 編碼對中文檔名的處理差異。
本地檔案名不變，玩家下載後看到的仍是 GitHub 上的資產名。

## 下次發版流程（可直接複用）

```powershell
# 1) bump package.json version → 重新 npm run package:electron
# 2) 打 tag 並推送
git tag v1.0.3; git push origin v1.0.3
# 3) 建 release（用 git credential 的 token）
#    POST https://api.github.com/repos/wa0966766851-ship-it/new-chat/releases
#    { tag_name: "v1.0.3", draft: false, prerelease: false }
# 4) 上傳兩個資產（curl --upload-file，ASCII 名，endsWith 匹配即可）
#    POST https://uploads.github.com/repos/.../releases/<id>/assets?name=seer-battle-simulator-1.0.3-portable.exe
```

注意：上傳 174MB 走 GitHub uploads 偶發 408/連線重置，
用 `curl --retry 5 --retry-delay 10 --retry-all-errors` 可自動恢復。
