# 自製待機與受擊第三輪

## 使用者否決本輪畫風與清晰度；尚未完成

本輪「雙側可以播放」不是美術驗收通過。使用者指出墜星的生成待機換了畫風、變糊，以及先前引用的去背圖本身缺素材。不得再把六刃流程複製到其餘角色後宣稱全部完成。

已查證：先前當作原稿的 public/elf-art/wuxu_zhuixing_body.png 為 762×1000，缺少部分頭後光環與能量細節。它不是最初原稿。新收到的真正原圖已保存在 docs/custom-anim/drafts/20261105-zhuixing-original/original-user.png，1086×1448；SHA-256 見同目錄 source-review.json。

清晰度根因：3×3 來源總共 1254×1254，每格只有 418×418；最終墜星來源畫布 368×432，可見角色約 320 像素高，戰場再放大。減半 pixelsPerUnit 只能維持顯示尺寸，不能維持紋理清晰度。補幀也不能補回真實細節。生成圖改寫了臉、比例和材質，待機與出招的姿勢來源不同，另有風格跳變。

停止後續發佈：三隻清綠幕後的重製仍在 build 草稿，未再替換 public。先前已發佈的 v3 只是實驗版本，不是品質完成版；本輪未更新桌面包、exe 或網站。不要誤認此報告已解決畫風問題。

下一階段：以真正原稿為唯一視覺基準；保留原圖顏色／解析度的局部待機，再獨立製作出招與受擊關鍵姿勢。單張白底圖沒有原始圖層、被遮擋區域或真正透明度，不能聲稱無損恢復全部光效。先驗證一隻原稿待機，確認沒有整圖漂移、破洞、硬切或畫風變化，再擴展另外三隻。不能用 96 格資料或測試全綠當成畫面品質證據。

## 六刃樣板

- 新畫三個受擊姿勢：中招、後仰、回復；最後回到同一張待機圖。片段 8 格、24fps。
- 待機六張完整關鍵圖先去除灰霧背景，再用離線雙向光流補過渡。正式片段 96 格，47 個不同的圖像格，其餘為合理持有時間與回到起點。沒有把 96 格說成 96 張手繪。
- 遊戲只播放製作完成的圖集，沒有安裝或執行 OpenCV 的需求。開發工具放在 `.seer-cache/art-tools`；沒有加入網站的依賴或初始下載。
- 減半來源解析度，同步減半 pixelsPerUnit、畫布、所有武器錨點與腳底基準，維持原本世界尺寸。圖集 3,988×1,641，下載 7,854,144 bytes；解碼圖像 26,177,232 bytes。此數字不是整個遊戲或 GPU 的總記憶體用量。
- IAB 3016 正式 BattleScreen 實播：待機兩個階段、P1/P2 受擊、回到待機、近戰方向。兩張待機截圖可見衣襬輪廓改變，頭腳沒有整張平移。
- 當前只驗 1110×823 的瀏覽器畫面。未做本輪桌面版、手機尺寸或網站部署。
- 仍有缺點：細刀鏈可能有補幀形變；出招的關鍵畫面數仍偏少。本輪不宣稱達官方品質。

## 可重做的製作步驟

來源、生成紀錄與提示方向在 `docs/custom-anim/drafts/20261105-liuren-v3/`。舊 v2 spec 已不是六刃目前的正式素材，不能重跑整批 v2 然後覆蓋第三輪。

```powershell
npm install --prefix .seer-cache/art-tools --no-save --package-lock=false --ignore-scripts @techstark/opencv-js@4.12.0-release.1
node scripts/experiment_idle_flow.mjs docs/custom-anim/drafts/20261105-liuren-v3/idle-clean-source.png
node scripts/prepare_liuren_idle_v3.mjs
node scripts/build_pose_animation.mjs --spec build/custom-idle-v3-poses/wuxu_liuren.json --out build/pose-animation-idle-v3
# 檢查草稿後才更新本機素材：
node scripts/publish_custom_animation.mjs --id wuxu_liuren --source build/pose-animation-idle-v3 --publish
```

受擊來源的重做入口為 `prepare_liuren_hit_v3.mjs`，需要兩張已留存來源圖；先重做受擊 spec，再執行上方待機入口。`build/` 都是可重建中間產物，不能把唯一原稿放在那裡。

補幀原理參考 [OpenCV 官方文件](https://docs.opencv.org/4.12.0/db/d7f/tutorial_js_lucas_kanade.html)。光流可以估計鄰近畫面的移動，不能替代人體結構或補出被遮住的造型；衣襬變化太大、手指和細鍊不一致仍須重畫或降低幅度。

## 特效複用與下一步

`public/elf-fx/holyPuni/index.json` 已有官方特效圖塊；`fi` 是來源影格索引，不能把它當這張 PNG 有多少動畫格。單一圖塊不是完整可播放特效。要復用原生演出，必須連同時序、位置、UV 與混合方式一起取出，還要剔除原角色本體。

蝕言、帝辛、墜星已匯入 v3 並在 IAB 正式 BattleScreen 1110×823 實播 P1/P2 受擊與回復，截圖見 review-20261105/*-v3-hited-p1.jpg、*-p2.jpg；帝辛接近斬擊、墜星向上開砲與對手爆炸仍保留。靜態截圖不是流暢度或風格通過的證據；本輪畫風與清晰度已被使用者指出不合格，依上方原稿流程重做。

`node scripts/audit_custom_motion.mjs` 會列出重複底圖的受擊空殼；`--strict` 在仍有空殼時回傳失敗。這是資料缺口檢查，不是畫面品質評分。
