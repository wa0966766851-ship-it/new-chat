# 自製精靈動畫完成目標與驗收

目標：墜星、蝕言、帝辛、六刃的待機、物攻、特攻、屬性、額外行動、受擊與第五演出，與本專案已接入的官方動畫並列觀看時，角色清晰度、動作自然度、出招辨識與命中感達到可接受的相當精細度。本文件不把可播放、測試通過或影格數量視為美術完成。

## 歷史問題與處理原則

| 已遇到的問題 | 原因／不得再採用的做法 | 新原則 |
|---|---|---|
| 整張角色平移、來回擺動 | 用容器移動代替角色動畫 | 腳底與重心穩定，髮尾／衣物延遲變化；近戰衝刺只用在出招 |
| 拆件破口、斷頭、頸腰接縫 | 沒補被遮住區域就硬切並拉動 | 待機以連續網格與局部權重保持完整紋理；大動作必須補姿勢或補畫遮擋區 |
| 待機物件一直轉 | 以旋轉堆動感，不符合物件重量 | 禁止整個光環、武器無緣由持續轉圈；局部節奏配合角色設定 |
| 動作畫風與原畫不同 | 生成待機重畫了角色，替代原本立繪 | 原畫為視覺主來源；生成只補必要姿勢，逐張同尺寸對照 |
| 動作變糊 | 九格總圖僅 1254×1254，角色只有約 320 像素高再放大 | 重要姿勢各自高解析輸出；實際來源像素須支撐顯示像素；禁止以放大補清晰度 |
| 墜星缺光環與能量細節 | 不完整去背圖被當最初原稿 | 使用者提供的 1086×1448 原稿為唯一基準；舊 body.png 不作原稿 |
| 去背仍改臉與顏色 | 生成器即使要求去背也可能重畫 | 保存原檔 hash；以原始 RGB 恢復角色主體，透明邊緣另驗；不宣稱完全無損 |
| P1／P2 背對對手 | 靜態與動態混用方向、重複鏡射 | 每個實際來源分別確認；左 P1 向右，右 P2 向左，只翻一次 |
| 打不到或超越對手 | 以固定距離平移、不看角色實際範圍 | 沿用實際角色落點與武器錨點，分辨原地遠攻／接近物攻 |
| 動作後才出傷 | 命中時點未接播放器標記 | 角色動作、對手受擊、主傷與後續傷害依既有事件順序同步 |
| 受擊空殼 | 有 hited 名稱但重複待機圖 | 明確中招、緩衝與回復，實播受擊後返回待機 |
| 模糊的完成宣稱 | 用 no-crash、資料數或測試代替觀感 | 逐隻、逐側保存實播證據與未解缺點；玩家品質未通過則維持未完成 |

## 玩家驗收清單（每隻各自通過）

1. 原畫：臉、材質、服裝、配色、武器比例對照原稿無明顯風格跳變。待機主體不以生成替代原稿。
2. 清晰度：正常對戰大小能看清臉與材質，不比同畫面官方精靈明顯模糊；記錄來源可見像素、實際顯示像素與 DPR，不能只報圖集大小。
3. 待機：連看至少三個循環，有呼吸／衣物／頭髮等合理變化；沒有整體漂移、機械晃動、無理由轉圈、迴圈跳格或硬切。
4. 身體：頭腳武器完整；關節無裂縫、分身、軟化彎槍、重影、光效蓋臉或透明破洞。
5. 物攻／特攻：有蓄勢、出手、命中、收招；六刃／帝辛能辨識接近斬擊，墜星為向上開砲與對手上方落擊，蝕言重點為額外行動。
6. 受擊：中招有身體反應，腳底與重心合理，受擊完回到相同原畫待機；不因高倍速卡住。
7. 方向／定位：兩側分別出手、受擊、額外行動，面向中央且特效到達對手；用 1110、1920 與窄畫面檢查，不能把一種尺寸代表全部。
8. 播放：靜態、簡易、精靈動作與 1／2／5／10 倍模式可正常結束；資源未載入／失敗時有降級與重試，不鎖住回合。
9. 資源：記錄下載與解碼圖集、兩隻同場資源負擔；美術製作工具不進網站依賴，動畫按需載入；不以全球縮圖滿足單張圖集上限。

## 玩家否決：水中折射感，以及撤換

原因是移動區域中心、固定邊界的橢圓權重，會改變區域內的紋理比例。前次只驗證網格不翻折，沒有驗證金屬／衣料的形狀保留；以此宣稱自然是錯誤的。已清除四隻 v4 試作規格的 idleZones，停止擴散該方法。另三隻的原解析度匯入規格已準備，待機仍未完成，不用無動作冒充通過。

墜星現在只先做兩個獨立浮游武器的剛性分層：以來源座標多邊形分配原有 RGBA 像素，身體保持完整、不變形，物件四角使用同一個旋轉／位移。首次分層漏了左側武器翼片，已目視發現並擴充分層範圍；修後原大小查看兩個物件完整。這不是切斷身體關節，不需要憑空補畫手腳。

新增 `tests/customRigidProps.semantic.test.mjs` 驗證每個原像素恰好落在一層、RGBA 不變、96 個相位所有邊長與對角線保留、循環閉合、匯入後身體幾何不動；編譯器禁止把這種剛性附件與舊橢圓場混用，避免播放端覆寫附件。新的墜星圖集下載 7,194,370 bytes，RGBA 35,640,276 bytes；比前版未明顯增加，網格頂點大幅減少。

3016 試播已更新，兩側播放器載入成功；`rigid-props-clear.png` 保存目前完整畫面。只有浮游物先恢復正確運動，身體暫時靜止，不能當成本目標已完成。下一步須以服裝固定點／材質邊界設計關節與遮擋補畫，並檢查根部接縫；不再靠調大平滑變形補動感。出招／受擊及另三隻仍待完成，public／桌面／網站沒有發布這個中途版本。
