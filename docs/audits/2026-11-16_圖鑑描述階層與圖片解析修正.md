# 圖鑑描述階層與圖片解析修正

使用者附件暫存路徑已失效，無法直接確認原圖。以奈尼芬多正式長描述重現。

- 原因：共用RichDescription依賴`block`等工具樣式，獨立入口未完整產出時span退成行內，段落及縮排混在同一行。圖鑑樣式明確鎖定data-rich-kind的區塊排版、換行與最小寬度，避免依賴掃描結果。
- 圖片：列表先前直接用seerId或圖鑑內部id組合網址，與介紹的皮膚／自訂圖片／名稱對照來源不同。新增延後載入Avatar元件，共用ElfAvatar解析，不再將內部ID當官方素材ID，保留原按需載入。
- 官方API https://api.seerapi.com/v1/pet/264 確認264為原版奈尼芬多；目前不更換原版素材或猜測其他形態。原先目視就判定264為錯圖的說法已更正。因附件缺失，不能宣稱已核對使用者原畫面中的特定錯圖。

驗證：獨立型別及正式建置／HTTP身分檢查通過，新版1794841761057。新增tests/atlasHierarchy.browser.test.mjs，以奈尼芬多原文在實際瀏覽器驗證逐行block、多層縮排及padding=depth×16、圖片來源264和無執行錯誤。PNG及PDF產物集中shots/encyclopedia/naifen-*；PDF轉圖目視確認三欄、長文完整與階層。驗收服務及隔離瀏覽器已清理，不修改使用者圖鑑存檔。
