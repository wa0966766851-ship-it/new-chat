# 2026-11-10 秒殺、抗性、資料包與新精靈動作

## 範圍與裁定

- 真正的秒殺／瞬殺統一使用正式 instant_kill 請求與結算；免疫秒殺、禁止觸發、致命抵抗、特殊存活沿用共用管線。
- 每隻精靈、每個來源獨立計數，成功擲中後清零；下場清除，下次登場重新開始。機率為零、來源禁止秒殺或任一方死亡不計數。正機率使用遞增 PRD，第 100 次有效判定最遲必定擲中，仍須經免疫攔截；保底不等於必殺。
- 不改「消耗最大體力若干／全部」與「最大體力 100% 加高額真傷」等原文屬於體力修正／傷害的機制。

## 入口整理

| 入口 | 處理 |
| --- | --- |
| 通用 instant_kill 積木、持續技能、魂印、印記 | 共用計數；持續效果保留施放來源名稱，不改用本回合其他技能名稱 |
| 未來戰甲 | 正式命中後依陣亡隊友數計機率；未命中與對手行動不觸發；移除直接扣光體力 |
| 狂暴者 | 原有 115 真傷獨立保留；秒殺分支改正式請求；對手行動不重複觸發 |
| 瞬殺特性 | 7% 機率走共用計數與秒殺請求，移除以高額真傷代替秒殺 |
| BOSS 秒殺特性 | 共用計數與正式請求；疾行仍免疫瞬殺，擴展目標也逐一保護 |
| 恐懼化身舊註冊表 | 萬念歸墟機率分支接共用計數；保留正式積木入口 |
| 湮滅之主舊註冊表 | 絕滅分支接正式秒殺，不用高額真傷模擬 |

計數存放既有個體 RegistryState 並加入 clearOnSwitch，戰鬥快照可保存。來源由印記 ID／原始定義名稱與來源種類識別。具名 Kit 使用繼承式 context 包裝，保留原本即時狀態 getter 與 BattleContext API。

## 聖界套裝

由 battleResistances 統一提供實戰抗性：唯一最高抗性提升至 100%，其餘歸零；並列最高保留原配置。傷害抵抗與異常抗性都讀同一規則，原始編輯器配置不覆寫。共通異常抗性可以獨立判定，不依賴是否選到該異常槽。只有真正抗性成功回報 resistance 時觸發套裝回血，魂印／特性／其他免疫不冒充抗性。原有異常最長兩回合條款保留。

## 資料包

觸發對照表從完整 sequenceContract 拆為輕量 sequenceTriggers，資料建構不再把整個戰鬥執行器拖進初始依賴。原始預設名冊移至 defaultElfSeedsSource.ts，新精靈原始名冊在 newElfDefinitions.ts。執行期讀無損壓縮資料；建置將完整還原結果逐欄深比較，原文、積木、順序及公開匯出保留。沒有調高門檻。更新方式見 docs/guides/elf-update-workflows.md。
