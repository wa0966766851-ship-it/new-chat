# 舊背包積木修復與桌面來源追查（2026-10-21）

## 實際根因

桌面捷徑開啟本機 `http://localhost:3000/`，使用 SeerBattleSim 的 Edge 專用資料夾；不是網站或獨立 EXE。原啟動器偵測到既有伺服器就略過新建置，現改為即使伺服器已在運行，仍核對來源與 dist 時間。

真正造成這次雷伊效果整段消失的是舊存檔：實際魂印原文383字，新版390字，包含乘號、換行等差異；神明、雷神亦有歷史措辭。既有修復僅比對當前全文，實際舊版被跳過。描述同步後看似最新，卻仍沒有 Kit，戰鬥開始設定沒有執行，連帶影響回合初、雙倍弱化及麻痺副作用失效。先前使用「當前資料刪除 Kit」製作的舊存檔測試不足以發現這條路徑。

## 修復與保存邊界

- `savedSkillCorrections.ts` 統一補回同 ID、名稱、精確已知歷史原文的內建魂印、特質、技能與技能池。雷伊8份，其他歷史定義33份；後者逐筆以 Git 原文核對並在 JSON 登記來源。只正規化換行，不用模糊相似度。
- 保留既有非空積木、明確 kit／registry／none 模式、自訂原文、自訂 ID、配裝、個體、技能槽及 PP。不是重置整隻精靈。
- `savedBuiltinStorage.ts` 在 React 第一次讀取前處理倉庫覆蓋、雙方上次陣容、雙方背包預設及自訂精靈六條儲存路徑。先保存原字串，再寫回；損壞 JSON 個別隔離，備份失敗不修改該筆。
- 備份鍵為 `seer_before_builtin_kit_repair_20261021_<原鍵>`，每鍵只備份一次。本機桌面資料夾已實際載入更新程式，主控台回報5組修復；自訂精靈清單為空，不需寫入。
- 已開打的舊戰局不熱改，必須重新載入程式並開新戰局。網頁正式站尚未部署本批。
- 使用者原資料與完整快照只放在忽略的 `build/web-review-20261020/`，沒有加入版本庫。
