# 強制執行命中效果修正（2026-10-18）

依使用者裁定：強制執行命中效果，不能連帶強制大部分固有效果；命中效果自身或其他來源附加固定威力時，須走正式傷害公式。摩哥斯「王·墮落絕語」的效果全隊共享，維持到原施加者下次成功使用「王·潰墮妖族」。

## 積木資料與通用執行

- `team_force_hit{untilSkill,powerAdd,perMarkId,perMarkAdd}`：隊伍規則記錄來源個體，跨換人、供隊友使用；原施加者成功使用指定技能才解除。
- 摩哥斯原文的50固定威力及對手每道埒殘銜闕再25，皆由此積木參數決定。威力在前置命中效果完成後、正式公式前才讀取當下印記；不能在BEFORE_SKILL就鎖死舊快照。移除同名舊無效處理器及舊威力轉換，避免重播或重複加值。
- `runForcedHitEffects`只取skill/attached的on_skill_use、on_hit條款，保留條件與成功失敗連鎖。不強制固有或攜帶條款，也不偽造ON_SKILL_HIT事件。
- 只有強制條款產生或其他來源已提供正固定威力加值時，請求既有正式公式重算；無固定威力時只執行命中效果。每次扣一次PP、效果執行一次，不以額外行動或真傷代替。
- 基礎威力0加50也進正式50威力公式；屬性技能仍不被強制變成攻擊技能。
- `sure_hit_force`接上正式必中與強制效果旗標；單次旗標行動結束清除，隊伍規則另依解除條件管理。
- 哈莫三招使用獨立的`recalculate_skill{powerMultiplier:2}`，僅限self_invalid且真正技能無效；MISS不能混用。
