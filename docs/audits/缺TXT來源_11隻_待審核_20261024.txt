  3. 重跑 npm run audit:block-migration 與 npm run audit:implementation -- --write。
  4. 報告的 TXT 欄會從「缺精確TXT來源」變成「原句片段吻合」或「原句需人工對照」，
     這時才進入真正的逐句語意核對。
