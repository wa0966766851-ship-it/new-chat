# 組4 待使用者確認（5029 已轉；5016／5028 保留包裝）

## 5029 雷神
- 「【自身不為滿體力時】」標題範圍：是否閘控下列 PP 無限制／雙攻總和／物理回血／特殊先制-1。舊 handler 不閘控，Kit 沿用。
- 「恢復己方至少70點體力值」：「至少」讀為恰好70。
- 「使用攻擊技能會以雙攻值總和視為當前攻擊/特攻值計算傷害」：沿用既有 atk_sum_calc（非組1的 stat_sum_as）。

## 5029 霆·禁雷敕令
- 「附加對手自身已損失體力70%的真實傷害，附加時若體力低於0則改為附加自身體力上限70%的真實傷害」：已損失體力指誰（舊 handler 用對手的；Kit 沿用）。
- 「自身體力低於最大體力⅓時則造成技能傷害提升3倍」：×3 或 +300%（舊 handler +200%，Kit 沿用 +200%）。
- 「無視對手免疫效果」：讀為無視攻擊免疫。
- 「消除成功則下2回合受到傷害翻倍」：依裁定1讀為攻擊傷害（舊 handler 的 damageTakenBoostTurns 無讀取端）。
- 「未擊敗對手」：Kit 在傷害後判定，舊 handler 在傷害前判定。

## 5029 異
- 「觸發成功則當回合令自身麻痺。每減少1回合令自身麻痺回合數+1。」：舊行為由 contextBuilders.addTimerTo 的旗標承載，兩句歸屬未結構化。
- 「當回合自身所有技能先制+1」以 prio_bonus 於先制判定時查詢（對手不處於能力提升）。

## 5028 瀾（保留包裝）
- 「登場前場上精靈存在護盾則額外複製雙方護盾總和並附加給自身」：登場前的前一隻我方精靈護盾是否計入。
- 「雙方護盾值每次發生變化時：每達到100則附加給1道對手千秋一淚」：累計或單次。
- 「每存在2道時若對方存在1道千秋一淚則死亡時消耗對應的道數令自身重生」：「對應的道數」指什麼。
- 引擎缺讀取端：護盾變化事件、30%護盾保留、水系使狀態機率100%、千秋一淚第3/4階效果。

## 5016 械／核心重構／王·超限共頻（保留包裝）
- 充能系統語意、「補充等量充能」分配到哪些技能。
- 「同時令己方變為被挑戰方」。
- 「末位充能」的指稱。
- 「消耗馬爾修斯隨機其中1個技能令本次消耗體力效果降低15%」。
