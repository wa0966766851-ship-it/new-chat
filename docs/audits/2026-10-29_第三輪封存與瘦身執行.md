## 防止再次膨脹

- 分享副本原先未排除桌面歷史版、新封存區、截圖與整理回執。現在由`tools/shareFilePolicy.ts`集中排除這些目錄，也排除本機動畫來源設定，避免備份與本機資料進入分享副本。
- 舊免安裝打包原先整包複製`.seer-cache/`，可能再次帶入測試瀏覽器與解包資料。現在只複製伺服器實際讀取的head、body、type、abnormal、buff、signbuff、card與release-assets八類資源；正式圖像快取仍保留。
- Electron封裝新增`--no-zip`，僅在本機反覆建置時可使用，避免額外生成一份數百MB的EXE ZIP；預設正式流程仍會產生ZIP，未移除交付功能。
- 先前已修正動畫測試關閉後未回收profile；本輪未改動遊戲引擎與顯示邏輯。

## 封存位置與取回

本機`.local-archives/20261029/README.md`與`INDEX.json`保留所有來源、備份位置與成品去重對照。它們不進Git，也已排除分享打包。

```powershell
# 以實際備份檔名替換；需要可用的Python
python scripts/archive_workspace_artifacts.py --restore ".local-archives/20261029/browser-profiles/backdrop-browser.zip"

# 僅本機反覆建EXE時，可以略過額外ZIP；正式發布保留預設流程
npm run package:electron -- --no-zip

# 更新本機封存索引
node scripts/index_local_archives.mjs
```

還原會先驗證備份，再寫入新的`build/restored/`目錄，避免覆蓋目前專案。備份是標準ZIP64，也可用相容解壓工具取出；原相對路徑及時間另存於ZIP內manifest。歷史EXE直接按INDEX中的backupZip與member取回，網路安裝器須配合同版payload。

封存工具預設只預覽；同批`--apply`不會覆寫既有回執。中途停止可用`--apply --resume`接續；已完成備份、來源刪除到一半、來源被外部修改等情境均有保護。最多兩個工作同時壓縮，避免無限制並行。實際曾調整掃描方式並從回執接續，沒有關閉使用者視窗或服務。
