# 哈莫龍鱗循環：局部修復與驗收

本次只驗收魂印「鱗」的登場、屬性循環、減半累計、染色、能力上限與在場回合數；不代表整份魂印完成。

## 可編輯語義

- 登場：重置循環順序；保留本場戰鬥累計減半次數；新增3片持有者綁定的無色龍鱗。
- 對手造成技能傷害前：單一屬性依水、火、草循環。符合則按累計次數重複減半，將一片無色鱗染為第一個尚未持有的顏色，並重置在場回合數。
- 不符合：本次技能傷害歸零，己方存活龍系精靈六維上限逐次提升20%，後續減半次數增加一次；不推進屬性順序。複合屬性不冒充單一屬性。
- 自身造成的傷害不觸發「對手造成」條款。共用傷害上下文新增來源陣營資料，主攻擊與附加傷害均提供真實來源。

通用操作位於 `src/blocks/ops/typedDamageCycle.ts`，沒有按精靈名稱分流。順序、倍率、染色清單、指定隊伍屬性、存活範圍、成敗動作均由積木參數決定；成敗內嵌動作仍經嚴格合約遞迴檢查。

## 共用在場回合修正

引擎原先在每隻存活隊員的回合開始迴圈內增加同一個場上持有者的在場回合數，導致背包越大增加越多。現在每方每回合只增加一次，個體每次登場均重置；原有全隊回合開始事件與官方節點順序保留。
