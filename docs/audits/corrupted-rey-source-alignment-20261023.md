# 兩隻雷伊原文與積木對齊（2026-10-23）

## 本次發現與修正

- 魂印展示被改寫為執行摘要：恢復使用者全文，保留標題、層級、繳械／麻痺／入魔定義。原文保存在 `src/data/corruptedReyDescriptions.ts`，不再由積木摘要拼接。
- 回合開始積木的文字只描述能力提升分支：補回沒有提升時的先制、使用技能後繳械及墜霆的失敗懲罰。執行分支與展示文字同時保留。
- 未指定期限的魂印麻痺／繳械、暗影墮霆閃命中繳械，原先擅自填2回合：移除該覆寫，沿用引擎預設3回合；原文明寫2／7回合的吸取失敗繳械仍保留指定值。
- 魔化雷驅的基數誤取自身最大體力：正常與技能無效分支均改為對手最大體力的 50%／125%，仍是混沌·電系技能傷害。
- 沉淪混沌決在消除後才判斷回合效果，導致 ×2.7 落空：改為消除前讀取條件並排入本次技能傷害倍率。使用者明確裁定不放大同招百分比追加。
- 期限沒有變化時把待用追加傷害歸零：改為壓縮實際成功後才覆寫，仍只保留最近一次成功觸發，不累加。
- 技能增傷的類型需為「技能」，不能以「攻擊」代替：兩隻第五技依異常回合數計算的增傷改接 `outgoing_skill`，與百分比追加分開。
