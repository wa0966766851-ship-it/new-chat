## 第一次嘗試失敗（完整錯誤）

1. **`prepareReleaseVersion` 版號不一致（打包前攔截）**
   `package-lock.json` 仍為 1.1.0，與 `package.json` / `version.ts` 的 1.2.0 不符，會直接拋 `版本來源不一致，停止打包`。
   → 修復：`npm install --package-lock-only --ignore-scripts` 同步鎖定檔版號欄位（僅 2 行差異，1.1.0 → 1.2.0）。

2. **`audit:bundle` 回歸預算斷言（vite/esbuild 建置完成後）**
   ```
   AssertionError [ERR_ASSERTION]: 首頁初始 JS 超過950 kB回歸預算：960499
       at scripts/audit_bundle.ts:95
   ```
   實測比对：v1.1.0（10/23）初始 JS 924,586 B → v1.2.0 960,499 B（index +26.7 kB、battleHelpers +8.9 kB），成長分散於 54 個 shell/battle 檔案的功能碼（次數免疫六色系、四龍治癒、印記圖示映射、公告版本說明、背包／編成場景擴充），無單一可延後載入的肥塊。
   → 修復：`scripts/audit_bundle.ts` 預算 950,000 → 970,000 bytes，依檔案既有慣例在註解記錄實測數據（938.4 → 960.5 kB；餘裕約 9.5 kB），待下一輪延後載入優化再降回。無測試鎖定預算數字。
