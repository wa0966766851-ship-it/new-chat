# 1.0.3 重新打包與發布（DSH 2026-10-20）

## 為什麼要重打

1.0.2 的 EXE 是 10/19 17:22 打的，但之後三個功能是 19:13–20:08 才提交：
- PVP 雙側操作 UI（P2 獨立技能／換人／藥劑面板）
- 對戰資訊欄三模式（簡潔／傷害／完整）
- 回合摘要、精靈過濾、量級分色、回合/文字查詢

→ 已發布的 1.0.2 不含這些功能。

## 處置：版本遞增到 1.0.3（不覆寫 1.0.2）

理由：已下載 1.0.2 的玩家若看到「已是最新」但內容已變，會造成版本語義混亂；
且 GitHub 不允許同名資產覆寫。

## 教訓（寫進流程）

**發 Release 前必須確認「EXE 打包時間 > 最後一次功能提交時間」**。
本次疏漏：先激活更新通道（00:05），才發現包是舊的（17:22）。

檢查指令：
```powershell
Get-ChildItem dist-electron -Filter "*.exe" | Select Name, LastWriteTime
git log --format="%h %ad %s" --date=format:"%Y-%m-%d %H:%M" -5
# EXE 時間必須晚於最新的 feat commit
```
