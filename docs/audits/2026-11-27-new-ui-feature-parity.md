# 新版介面功能對照與缺漏

## 核對方式

比對StartScreen／ElfEditor的控制項與資料寫入，對照RosterWorkspace、TeamScene、BagScene及AegisTraining的實際入口。`features.ts`的live／delegated只代表路由登記，不作功能或視覺驗收證據。呼叫共用控制器本身不代表切換舊殼；但畫面仍是舊式編輯器、或新版缺少對應控制項時，明確列為缺口。

本表是逐項原始碼核對；正式瀏覽器操作的證據另記在單機培養驗收文件。尚未逐頁視覺驗收的頁面不標成已完成。

正式桌面包已通過型別、首頁啟動與隔離瀏覽器流程：新刻印三頁與繁體、120級／開戰體力、個體值／戰隊加成／致命值、純刻印外觀不改數值、存檔重載、蓋亞獨立外觀頁換皮膚、新版背包抽屜換人及首發保存。畫面已檢視，截圖統一放`.seer-cache/native-training-browser/`，不混放專案根目錄。

## 仍需移植或獨立驗收

1. **新增／進階自訂精靈編寫**已接入新版精靈工作坊，使用既有ElfEditor草稿／解析／驗證邏輯，新增新版導覽、摘要側欄與編寫面板，保留來源文字、手動編輯、積木、圖紙匯出匯入；原生刻印面板也可從工作坊開啟。正式瀏覽器已驗證手動／積木往返保留草稿、保存並返回背包。外部AI解析供應商的實際回應與所有作者功能分支未逐項驗收，不能把介面保存測試視為完整精靈效果驗收。
2. **巔峰選禁**已改用獨立原生AegisPeakDraft與共用資料層，不再跳回StartScreen。支援雙方12格原位編號、禁用原位保留、固定卡片比例、首發與配裝查看、3v3／6v6規則設定。語義測試涵蓋PVE／PVP及禁選數量；正式瀏覽器已完成3v3禁用、選用、指定首發與實際進入戰鬥。遠端連機不包含在這次驗收。
3. **精靈完整文字匯出／複製、詳細能力演算展示、培養資料比較分析**與舊詳情的呈現仍有差別。本輪補上魂印／技能複製與正式介紹匯出，不把這些當成完整分析工具移植。
4. **累計升級經驗**仍未完成。已查U端635個設定資產清單與實際升級程式，確認已檢查的升級介面向伺服器取得所需經驗；另保存舊版1–100級四欄表，但未可靠對應成長類型及核實全部數值。詳見[經驗查找紀錄](2026-11-27-original-level-experience-search.md)。不填網路近似公式，等級調整不因此受限。
5. **百科、星際探索、命運之輪、更新頁、自動測試及控制中心的詳細子頁**仍有共用舊元件的路徑。部分已有新版外觀，需逐頁視覺核對；不能只看LegacyScenes檔名推斷所有頁面都舊，也不能只看live旗標推斷功能齊全。
6. **雙機正式對戰、遠端選禁／結算及分享轉接**仍依先前缺口報告追蹤，本輪單機UI接入不代表雙機系統完成。

- 培養內複製／積木切換按鈕不再連帶選中或替換技能。

- 資料保存、正式初始化及畫面操作分開驗證；保留原有存檔與舊介面入口。

## 工作坊比例問題的根因與修正

使用者指出的截圖中，摘要出現在右側大欄，表單卻被限制到左側230px。原因是新版設定了新的欄寬，卻仍繼承舊版`.editor-form-panel { grid-column: 1 }`與`.editor-draft-summary { grid-column: 2 }`。因此不是單純調整卡片大小即可修復，需要同時明確配置欄寬與欄位位置。

新版現在明確指定左側230px摘要、右側彈性表單；1000px以下改上下排列。基本資料也改為名稱／圖片路徑／屬性／特質縱向排列、右側獨立皮膚預覽；預覽區180px高，不再把其餘輸入欄位所在整列撐到相同高度。700px以下改為單欄，調整只限新版工作坊。

驗收增加桌面表單寬度、摘要位置，以及1280×800、900×800下的表單邊界、輸入寬度和欄位位置檢查，搭配截圖檢視。新一輪正式產物需通過這些檢查才啟用。
