# 機甲、符文歸屬與附屬詛咒接續

保留既有未提交修改；本輪沒有推送、部署或打包 EXE。以下是局部機制驗收，不能作為397份全文驗收。

## 已實作與雙側驗證

- 首次減傷：新增可編輯 `damage_reduce_first{id,ratio,types,resources}`。要求護盾、護罩同時存在，每回合僅首筆非真實傷害減半；真傷、缺資源及完全免疫不耗次數。終段執行避免免疫搶走次數，依個體及回合隔離。取代械原先整回合減傷計時器。
- 異常解析：每回合第一種新異常即解析並免疫，既有記錄持續免疫；正式印記按種類數顯示，移除不存在的 `addMark`。透過隊伍觀察者讓場下持有者免疫己方在場隊員已記錄異常，回合末依記錄數恢復原持有者技能充能，不給接替者。
- 奧丁附加：新增 `rune_attach{side,slot,rune,withinRounds}`，對手槽1–5取得ᛈ、ᛁ、ᚦᚺ、ᚾ、ᛃ，自身槽取得ᚨ、ᛉ、ᚱᚷ、ᛇ、ᛖ；不覆蓋既有符文，附加時未激活，後續合法選擇對應技能才激活。第三回合不補附加。此項只驗證附加、激活時點及歸屬，並未驗收所有符文的戰鬥能力。
- 共用回合計數：先更新雙方在場回合，再派發回合開始；修正P1事件讀到P2上一回合計數的非對稱問題。節點順序未增刪，原headless順序測試8項通過。
- `first_move{neg:true}` 原先忽略neg；現在正反查詢使用同一真實先手紀錄，尚無紀錄不視為後手。
- 械、ᛏ的回合末恢復連鎖改 `heal_then` → `dmg_from_last`，按自身真正恢復量造成對手等量百分比傷害。雙側測試異血量上限、只缺100點與滿血，排除按對手最大體力計算或按溢出請求量造成傷害。
- 咒術師選招額外扣費現在包含三種附屬詛咒。控制「詛咒」禁止本體使用技能，只扣選招1PP，99→98；三種附屬詛咒能使用技能，正常與額外各1PP，99→97，仍發動一次怨靈魔咒。原97斷言保留在正確可行動情境，沒有以全改98掩蓋缺口。
- 修復測試的在場受方改存活5000HP，保留場下持有者1000→1250及PP4→5數值，並保留在場者普通技能使用及恢復相抵的PP4斷言；原1000HP的P2路徑沒有出手、PP為5；此處改用較高體力排除傷害造成的提前結束，未以原低血案例驗證普通技能扣費。
