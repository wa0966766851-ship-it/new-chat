## 後續發 Release 時必做

兩個 EXE 上傳後，取得 GitHub 該正式 Release 的完整 JSON（不含任何授權 header/token），再執行：

```powershell
node scripts/prepare_update_manifest.mjs build/release.json build/update-manifest.json
gh release upload v版本號 build/update-manifest.json --repo wa0966766851-ship-it/new-chat
```

清單產生器拒絕覆寫目的檔；附件上傳不使用 `--clobber`。新版本缺清單時，API 正常仍可查詢；API 限流且附件缺漏時會明確報錯。
