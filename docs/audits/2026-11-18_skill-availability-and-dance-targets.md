# 技能可選顯示、亂舞預選與技能欄空過（2026-11-18）

## 行為與語義

技能亮暗一律依 `skillSelectionBlock`；第五技能圓章不再因 PP 為零另行灰化。合法的零 PP 技能維持亮起，禁止選擇的技能即使仍有 PP 也灰化。保留 `aria-disabled` 與原因，不能選招時仍可查看資訊，不使用原生 disabled 阻止查看。PP 數字與圓弧仍顯示真實資源，亮起不代表補充 PP。

當 `legalActions`（含該模式的剩餘藥劑次數）只剩空過時，兩種介面的原技能區可直接點擊空過，顯示「點擊空過這回合」；Enter／空白鍵同樣適用。仍有合法技能、切換或道具時不啟用這個入口。既有自動空過設定保留。

亂舞保留攻擊／特攻提升12%，改用以下明確時序：

| 觸發 | 條件／目標 | 行為 |
|---|---|---|
| 自身登場 | 對方存活的場下精靈及額外精靈 | 預選1名，保存戰鬥個體 ID |
| 每回合結束 | 同上 | 替換舊預選；允許重新抽到同一名 |
| 自身造成技能傷害 | 預選仍在有效範圍 | 按該目標目前屬性／雙防另算技能傷害 |
| 自身離場／被擊敗 | 自身預選 | 清除 |

同回合多次出手沿用同一目標；不複製附加固定／百分比／真實傷害、恢復、異常等其他技能效果。主技能未造成技能傷害時不波及。選中者已出戰、陣亡或消逝時，當次不另抽替代者；等回合末重新預選。沒有候選時保存空清單，不保留舊標記。幻化／來源判定仍走既有通用效果路徑。

兩種對戰介面的上方隊伍節點以玫紅外框標示有效預選，搭配「◎ 額外攻擊目標（僅技能傷害）」圖例與無障礙標籤；隱匿精靈維持匿名，不揭露名稱。

## 實作邊界

擴充既有 `extra_random_target` 參數：`mode: prepare/clear` 與 `prepared: true`。亂舞由 Kit 的登場／回合末／出手後／離場／被擊敗節點組成，未在 BattleScreen 或 battleEngine 加入特定精靈名稱分支。未設定新參數的既有積木保留即時隨機行為。

預選狀態為精靈自己的 `preparedExtraAttack`，不是陣營共用的目標索引；傷害仍走 `applyDamageToElf(..., 'skill_attack')`。攻擊公式已計算技能克制，結算傳入 `elem: skill.type`、`applyTypeMatchup: false`，修正舊路徑再次套用持有者屬性克制的問題。描述、原始種子與封裝 Kit 已同步，執行 `pack_reviewed_kits.ts` 深比較核對打包內容。
