## 判定結果

- 58 隻內建精靈中，51 隻的預設外觀可對上 Seer API 原主。7 隻缺少已驗證的預設原主資料。自製精靈原有的專案標籤仍可使用。
- 合計 37 隻有可核對的預設標籤（含專案團體與精靈王）。其餘保留空白；故事裡提到其他團體，也不代表原主是其成員。
- 精靈王標籤對象：冰魄·柯爾德、柯爾霍德、聖光斯嘉麗、變革·馬爾修斯、蟲后·奧佩婭、怒濤·滄嵐、邪靈主宰·摩哥斯、不滅·艾恩斯、岳峙淵渟·卡修斯。馬爾修斯在「王·肅正協議」持有等價固有效果，卡修斯的「炫彩.山殞垣頹」在積木中明確標為精靈王特權。未將僅有通用「無微弱」效果的哈莫或混沌布萊克列入。
- 出沒地點、守護對象與出身分開標示。原版卡修斯可帶有「出沒於懷特星」，切成聖地卡修斯時按該外觀的資料重新判定。已手動覆寫的團體仍以玩家選擇為準。

## 後續調整

以上判定記錄保留首次核對背景。目前預設團體合併預設立繪及所有已登記皮膚原主，切換外觀不會改動標籤。使用者另指定御天龍神·哈莫與混沌·布萊克加入精靈王，並為兩隻治癒系列、無為龍者、龍錄天鋒、無極聖武及命運龍輪莫伊萊加上龍魂精靈。

出沒星球標籤取自圖鑑的出沒地點或同一精靈的已確認原型。已整理克洛斯星、赫爾卡星、阿爾法星、貝塔星、懷特星及幻影星。手動選定的標籤仍沿用使用者設定。
