# 獨立多本精靈圖鑑

依使用者最新決定恢復多本管理。獨立程式位於 `encyclopedia/`，桌面新增「精靈圖鑑」與「更新精靈圖鑑」捷徑，已核對指向本專案啟動器。

本輪修改：多本新增／切換／改名／刪除與備份匯入；主介面不再靜態匯入完整內建資料與介紹元件，改成按需背景載入。精靈與圖鑑切換只更新記憶體及輕量瀏覽偏好，不再每次寫入整份圖鑑。自訂精靈、圖片、屬性、編輯與匯出功能保留。

新增驗證檔案：`tests/atlasStorage.semantic.test.ts`、`tests/atlas.browser.test.mjs`。新增說明：`encyclopedia/README.md`。套件指令加入 `atlas:build`、`atlas:dev`、`test:atlas`。原本根目錄圖鑑實驗排除規則已移除，以納入程式來源；建置版本與日誌改由 `encyclopedia/.gitignore` 排除。未刪除既有專案檔案。

驗證：

- 多本獨立保存、重開還原、寫入衝突／損壞保護及圖片去重通過。
- 實際瀏覽器新增圖鑑與切換通過，量測切換約120ms，沒有觸發整份圖鑑PUT寫入；此為本機樣本，不是所有裝置速度保證。
- 獨立型別檢查、正式建置、前端／服務身分驗證通過。版本 `1794840768828`，前版保留。
- PNG、單隻PDF與整本PDF實際輸出成功；PDF檢查1頁／2頁，經轉圖目視確認三欄版面。測試產物集中在 `shots/encyclopedia/`。
- 桌面捷徑建立、目標核對及啟動器語法檢查通過。測試服務與隔離測試瀏覽器已關閉，使用者遊戲視窗未關閉。

尚有依賴積木檢視的延後載入區塊超過500kB；不在圖鑑起始載入路徑，沒有宣稱全部區塊體積檢查通過。此輪未重新實測全部57隻的長描述PDF。

資料位於 `%LOCALAPPDATA%\SeerEncyclopedia`，程式更新不覆寫圖鑑資料；使用介面備份會包含上傳圖片。主專案精靈資料變更後，使用桌面「更新精靈圖鑑」同步。
