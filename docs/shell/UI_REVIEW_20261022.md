## 完成

- 大廳橫向雙欄、直向重排，長列表只於區塊內捲動。使用使用者提供的清晰場景 `public/aegis/lobby-spatial.png`，不模糊背景。角色仍受原始圖片解析度限制。
- 頂部資訊預設收合，保留頭像與工具按鈕，移除重複頂部圖鑑／更新及側欄設定入口。
- 玩家頭像預設譜尼，可搜尋精靈更換或恢復預設，只儲存精靈 ID。
- 立繪左右／上下位置、縮放、完整／裁切及重設；拖動模式使用 Pointer Capture，平常關閉避免誤觸。保存並相容舊版只有 Y 位置的設定。
- 房主 P1／P2、AI／雙人同屏接原有 bridge 狀態；雙人模式不誤標 P2 為 AI。背包及編成新增完整戰前設定直接入口。
- 雙方背包同頁，頭像限制尺寸；修正編輯路由及返回時殘留 editorTab 問題。
- 替換預覽隊伍可建立存檔，替換首發更新 battleId，重複精靈／寫入失敗有提示。切換 P1/P2 保留當頁編成草稿，待命精靈不可指定為首發。
- 套裝／護目鏡／稱號分我方、對手選擇，使用舊版相同六個儲存鍵，裝備全隊生效，不須先選單隻精靈。
- 裝備列補上拖動事件並阻止原生圖片拖曳干擾，保留觸控、滾輪、鍵盤左右鍵。瀏覽器實測 scrollLeft 0 → 279，沒有誤裝備。
- 配裝保存失敗回傳實際存檔並提示，避免 UI 假成功而開戰讀到舊配裝。
- 背包／倉庫／編成／技能預覽接回共用 TypeIcon、SkillTypeIcon，包含複合屬性。
- 腐蝕者 percentBonus 原寫 0.10，計算器採百分點，實際只加 0.1%；修為 10。行為測試確認攻擊 500 → 550、特攻 400 → 440。

## 驗證與界線

- 內建瀏覽器檢查桌面、390×844 直向、844×390 橫向；直向大廳主要按鈕均在頁面內，沒有橫向頁面溢出。
- 清晰背景 naturalWidth=1772；`/seer/type/13.png`、`78.png`、`41.png` 等實際載入。拖動後重新整理仍保留位移。
- 初次新增背景時開發伺服器回傳 HTML，圖片走備援；重開本輪自己的 Vite 後確認清晰素材成功載入。不能只依 HMR 截圖推斷替換成功。
- 新增 heroLayout 相容／保存／首發邊界測試，接進 test:shell／test:ui。增加房主寫回、完整設定入口、P1/P2 配裝隔離、保存失敗及腐蝕者百分比斷言。
- 路由可達不代表原介面所有功能逐項驗收。部分頁面仍委派 LegacyScenes，尚未全部改成單頁版型。
- 本輪未進行完整戰鬥或連線實戰，不將 UI 測試當戰鬥正確率。
