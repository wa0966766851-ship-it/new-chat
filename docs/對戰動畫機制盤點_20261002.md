# 對戰動畫機制盤點（2026-10-02）

> 本文記錄修正前的狀態。後續已完成 [對戰動畫整理實作與驗收](對戰動畫整理實作與驗收_20261002.md)，目前播放行為請以實作紀錄為準。

本次只檢查與整理，不改播放行為。範圍為共用 BattleScreen 與其戰鬥元件；不包含首頁、特殊模式地圖、全域控制中心音樂圖示及一般按鈕滑鼠效果。以下「種類」依使用者看到的用途計數，不以 motion 標籤數量或 P1／P2 重複次數計數。

## 數量與現況

- 10 類戰鬥回饋：立繪出手、立繪受擊、自訂戰鬥艙出手、自訂戰鬥艙受擊、受擊邊框、飄字、中央結算提示、HP 條、異常徽章進出、護盾／護罩條。
- 5 類固定循環提示：低 HP、SIGNATURE、技能選中框、消逝、技能說明中的啟用符文。資料還可注入 specialBadge／mark 的動畫 class，屬於額外擴充入口，未另算固定種類。
- 5 類主畫面輔助介面動畫：自訂日誌側欄、魂印／特性說明彈窗、技能說明浮窗、顯示設定彈窗、精靈詳情彈窗。
- 7 組未接入的 CSS 戰鬥特效：劇烈震動、傷害數字、正向斬擊、反向斬擊、能量爆發、共鳴上升、幻影頻閃。搜尋 src 只有樣式定義，沒有使用 class 的元件。

因此按上述口徑，有 **20 類已接入的動畫／動態提示**，另有 **7 組未使用樣式**。不是同時播放 20 種，固定版面與自訂版面也不是同時啟用。目前精靈本體都是靜態圖，沒有官方逐幀、Spine 或 Unity 技能動畫。普通對戰結束彈窗本身沒有另加進出動畫。

## 為何容易看起來混亂

1. **結算事件雖有佇列，畫面動畫沒有完整共用時間軸。** 傷害預設只等 120ms、回血／HP 調整等 80ms，浮字卻保留 1～1.2 秒，HP 條需要 300ms。新事件可以在上一筆動畫完成前進入。這是交疊，不代表傷害判定順序錯誤。
2. **同一筆數字重複出現在兩處。** 固定版面同時有立繪上方浮字和中央 lastActionInfo。中央沒有定時退場，回血分支也未更新它，可能看到新回血浮字與舊中央傷害並存。
3. **所有技能共用向前衝。** 事件有 physical／special／property 分類、技能名與目標，但畫面只讀出手 side；屬性招與攻擊招的移動沒有差異，也沒有不同技能的特效。
4. **連續傷害的受擊提示可能提早關閉。** 每次傷害都設定同一布林震動旗標，再安排 400ms 後關閉。第一筆的關閉回呼可能在後一筆受擊期間將旗標關掉；旗標未換值也不保證每段都重播震動。
5. **出手優先於受擊。** 同一側兩個旗標並存時，立繪／資訊艙採用出手位移，受擊震動被蓋過，邊框仍可能變紅。
6. **浮字沒有密度控制。** 按 side 篩選後全部排成直向串列，沒有顯示上限、合併或固定讀取區；多段伤害、附加傷害、回血容易堆滿。
7. **浮字跟 side，沒有綁定上場精靈身份。** 短時間換人後，尚未消失的前一隻浮字可能顯示在新精靈位置，容易看錯歸屬。
8. **中央提示 key 不完全唯一。** 固定版面使用 side＋amount＋turn，自訂版面使用 side＋amount。同一回合相同數字連續出現時，不一定重新播放進出動畫；它本質上只是「最近值」，不是逐筆事件清單。
9. **固定與自訂版面觀感不同。** 固定版面有立繪與浮字，自訂版面使用整個資訊艙位移與中央大數字；自訂版面沒有呼叫 renderSprite／renderPopups，因此不是把同一組動畫改位置而已。
10. **快速模式縮短結算等待，沒有一致縮短視覺。** `?fast=1` 將佇列等待歸零，但 UI 0.35／0.45 秒、浮字移除計時與循環提示依然存在，可能讓數字更新比動畫可讀速度更快。全域 reduced-motion 規則只處理 ios-panel／ios-card transition，沒有全面涵蓋戰鬥 motion 與 pulse。

## 建議整理順序

1. 統一「出手 → 命中回饋 → 數字／HP 變動 → 收束」的視覺時間軸，明確限制哪些提示可以並行，維持戰鬥判定與呈現分離。
2. 立繪上方保留即時數字，中央改成一筆行動摘要，不再重複跳同一筆數字；每筆帶唯一事件 ID 與精靈身份。
3. 限制同時浮字數量；同來源密集傷害可做總額＋段數，完整明細留在日誌。限制呈現不能丟掉真實結算紀錄。
4. 攻擊才前移，屬性／恢復招採用小幅亮光或狀態提示；一般受擊輕微回饋、暴擊加強，不移動整個資訊艙。
5. 循環提示優先保留必要的低 HP；SIGNATURE、選中框、符文、消逝改為清楚的靜態標示或短暫提示。
6. 提供完整／簡化／關閉動態三種一致模式，涵蓋 motion、CSS 與浮字時序；重來、換人、離場各自清理所屬播放事件。
7. 整理完目前通用動畫後，再試接官方待機／技能動畫；避免增加第三套不協調的播放機制。
