## 2026-10-19：打包副本與磁碟空間

### 原因與修正

- 舊 `SeerSim_share/dist/win-unpacked` 把輸出包入 `dist` 再收進自己，留下約59.88GB巢狀產物。現行Electron設定已有獨立輸出，本次清理的是舊副本，不是正式安裝包。
- `prepare_share`漏排除`build`與`dist-electron`，會複製舊產物。現在排除兩者，拒絕來源覆蓋、來源上層、未標記的非空輸出與目錄連結。
- 版本打包工具改用`build/.work/exe-*/source`獨立副本，按lockfile執行`npm ci`，成品收集後由`finally`清理整份副本，包含其node_modules。
- 一般Electron打包有互斥鎖。成功或失敗後清理`build/electron-app`與`dist-electron/win-unpacked`，另存去重紀錄；保留正式EXE、網路安裝payload、下載快取與來源素材。
- 舊ZIP／IExpress流程使用唯一`.work-*`與系統暫存目錄，結束後清理，不再整個刪除`release`。建置失敗立即停止，不以舊dist繼續打包。
- 更新、素材快取與瘦身測試改為`finally`清理自己的合成資料。超過24小時的舊同類暫存可由清理工具回收。

### 使用方式

| 用途 | 指令 | 留下的內容 |
|---|---|---|
| 一般Electron封裝 | `npm run package:electron` | `dist-electron`正式成品及報告 |
| 封裝後檢查解壓內容 | `npm run package:electron:inspect` | 另外保留中繼副本，供artifact／renderer測試 |
| 獨立版本打包 | `npm run build:exe`（以package.json現有指令為準） | `dist_release/<版本>`；工具可加`--keep-work`保留副本 |
| 舊免安裝ZIP／EXE | `npm run package:portable`／`npm run package:zip` | `release`成品；PowerShell工具可加`-KeepWork` |
| 預覽歷史暫存清理 | `npm run clean:build-artifacts` | 不刪除，只列候選與容量 |
| 執行已界定範圍清理 | `npm run clean:build-artifacts -- --apply` | 清理回執存於`docs/audits/build-cleanup-20261019.json` |

`build`其餘舊研究／網站套件可能含獨有內容，沒有只按日期或副檔名整批刪除。原始素材、玩家資料、正式安裝包保留。

- 封裝流程以替代建置步驟測成功、失敗與保留模式，核對中繼清理、正式安裝包及必要payload保留、鎖釋放。
- 桌面更新17項安全測試、素材快取及既有資源去重測試通過，並確認測試暫存自動清除。
- TypeScript工具可編譯、PowerShell語法解析通過。本次沒有重新打出或啟動EXE，不能將上述測試當成新版成品實測。
- 戰鬥測試交GLM繼續。已核對的本機回歸報告35支全綠；這不是GLM尚未交付部分的驗收，也不是397份全文正確率。

實際刪除項目、bytes及完成狀態以[清理回執](audits/build-cleanup-20261019.json)為準。

本次107個已核對候選全部清理完成，共60,099,902,762 bytes（約60.1GB）；其中舊免安裝副本4030檔與保留ZIP逐檔核對SHA256後移除，空目錄保留。舊分享副本原始碼與lockfile、正式1.0.0／1.0.1 EXE仍存在。

## 2026-10-19：1.0.2 桌面版與四個死鍵修復

- 復核GLM的9b4a874基線：397份路由存在不等於語意驗收完成。補上御天陣威力與鋒毫三項只寫不讀狀態；使用通用威力查詢、限期事件、當前體力消耗及等量百分比傷害，沒有新增專屬引擎分支。

- 馬爾修斯3393原圖實際朝左，P1鏡射／P2保留，包含幻化來源URL與實際ElfAvatar DOM測試。晨曦之星戰甲經SeerAPI套裝447核對，加入完整官方立繪與來源、裝備ID及SHA256回執。
- Electron預設自動遞增修訂版，同步version.ts／package.json／lockfile；`--keep-version`可關閉。最後自動ZIP該版本EXE，成功／失敗清除中繼；檢查模式可保留後驗收再清理。合成測試實際驗證ZIP內容、舊版排除、失敗清理及鎖釋放。
