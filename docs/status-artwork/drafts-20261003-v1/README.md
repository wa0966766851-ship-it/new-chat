只修復透明處理誤吃深色底造成的斑塊：各圖框內改為一致不透明深藍底，恢復腐朽盾形的灰綠實心填色，清理框外青色碎點。保留八種圖形、配色、切角框、四欄兩列順序、繁體中文標名與縮圖位置。整張確認圖為不透明深色底，不新增圖案、光效或文字，不重新設計。
