## 一、「減半／翻倍 N 次」逐條檢查

| 位置 | 原狀 | 修正 |
|---|---|---|
| 克塔亞特「非真實傷害減半 n 次」 | 每筆只減半一次，最多 n 筆 | 每一筆都 ×0.5^n（n＝當下在場受真傷次數，即時更新）。runtime 新增 `powRegistryKey` |
| 滄嵐「每 100 點護盾減半一次＋上限 1/3」 | 完全沒做 | 回合開始快照，直到下回合結束，每次受到固定／百分比傷害 ×0.5^n，上限為雙方當前護盾總和 1/3；下場保留 |
| 聖靈邁爾斯 八荒 | 每次 ×0.5^(1+每10%) 正確；中途登場沿用舊回合的次數 | 中途登場只套「每次受到非真實傷害減半 1 次」 |
| 聖靈邁爾斯 天佑 | 等量百分比傷害打成「對手最大體力 10%」 | 改成等於自身恢復量 |
| 淨世洗禮頌（命中與無效補償兩處） | 翻倍次數被封頂在 6 次 | 移除上限，每 10% 都翻倍 |

## 二、無極聖武

- 砥礪（戰鬥百科：受真傷後若本回合未執行過附加異常效果，回 80%）補上「本回合未附加過異常」判定（觸發不移除異常，第三輪更正）；登場當回合結束判定：觸發成功 → 3 回合亮節；附加失敗或未觸發 → 3 回合威怯。
- 亮節、威怯、武誅改為印記（回合數），效果照官方：
  - 亮節：≤50% 的異常附加機率降為 0（通用文字、模板、積木、套件四條路徑都接上）；回合結束為對手 0 PP 技能回 5 PP。
  - 威怯：自身造成的非真實傷害 −60%。
  - 武誅：對手為無極聖武時先制 −2；體力 >1/2 受攻擊傷害 +50%，<1/2 造成攻擊傷害 −50%。
- 英雄之耀：開戰時每層其他能力值（體力、防禦、特防、速度）+雙攻差值 15%；登場時每層為對手附加 1 回合武誅。
- 特性的攻擊效果：無視對手能力提升／護盾／攻擊免疫；對手有武誅時 ①每回合 +20% ②能力提升視為下降 ③自身能力下降視為對手能力下降 ④每 100 盾罩 +10% ⑤無視攻擊免疫成功附加 3 回合威怯；使用後消除武誅；沒有武誅時附加等同英雄之耀層數的武誅。
