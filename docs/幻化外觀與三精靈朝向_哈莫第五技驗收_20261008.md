# 幻化外觀、三精靈朝向與哈莫第五技

## 修改與原因

1. 實際查看 `body/79.png`（艾斯菲亞）、`body/418.png`（艾斯菲格）、`body/3809.png`（龍神哈莫）：原圖斜側朝左，不應登記為正面／未登記。名稱與實際來源規則均改為 P1 鏡射朝右、P2 保留朝左。頭像不跟著鏡射；其他精靈的朝向表未批次反轉。
2. 幻化只替換外觀：保留原本戰鬥身分，但頭像、立繪、身高、素材呈現方式使用幻化目標。移除以原精靈 ID 強套雷伊頭像裁切的判斷，避免幻化後仍被原素材規則覆蓋。
3. 換圖與同網址反轉重新定位；新圖載入前不沿用舊圖的可見邊界。解除幻化後，來源、朝向與身高重新回到原精靈。卸載清除圖片載入監聽；像素量測保留快取，不每幀重算。
4. 哈莫第五技原有通用次數型無效入口實際可執行，本輪未額外新增一份專屬無效判斷。擴充正式戰鬥測試，避免只看到 timer 就宣稱實裝。
