# 屬性技能圖標與回廊存檔同步

## 範圍

本輪依使用者指示停止效果定義補齊，只修正顯示與肉鴿存檔同步。不修改戰鬥引擎、精靈註冊表、既有效果語意，不提交其他 AI 正在進行的變更。

## 原因與處理

1. 部分技能畫面直接用 `skill.type`，舊存檔的屬性技能因此仍顯示火、水等圖標。新增分類優先的共用投影：`category === '屬性'` 時圖標與標籤統一為無屬性，使用已有的 `/seer/type/prop.png`。物理／特殊技能，包括實際轉化後的技能，保留攻擊系別；不改底層技能資料或戰鬥公式。
2. 編輯頁的屬性技能系別欄改為無屬性提示；改回物理／特殊分類後仍可設定系別。首頁複製文字、編輯頁拆解用文字也遵守同一顯示規則。
3. 星蝕回廊原先直接讀取完整舊精靈快照。現在進入回廊、或當前精靈資料池更新時，以精靈 ID 匹配，更新內建精靈的名稱、系別、種族值、魂印、特質、效果定義、圖片資料與技能池；已選技能以精確技能名稱匹配更新，不強制換回預設技能組。

## 存檔保護與邊界

- 保留地圖、種子、隨機序列、章節、貨幣、藥劑、遺物、紀事、隊伍順序與出戰／待命名單。
- 保留個體 ID、等級、學習力、刻印等養成、淬鍊、異常、印記、存活規則、體力與剩餘 PP。種族值有改版時才重新計算面板；保留已損失體力、死亡與神降負血，不自動回血復活。
- 新 PP 上限降低時限制溢出 PP；不補滿 PP，保留合法的個體／技能 PP 偏移。
- 自訂精靈、額外精靈、不存在於現行資料池的精靈、技能石與無法精確匹配的技能，不擅自覆蓋。來源已改名的技能需另做明確遷移映射，不能猜槽位替換。
- 有未結算 `pendingBattle` 的局不改規則。結算並返回回廊後再同步；未結算局不應被宣稱已更新。
- 每局首次同步寫回前，將完整舊局面另存於瀏覽器儲存鍵 `INTERSTELLAR_ECLIPSE_RUN_BEFORE_DEFINITION_SYNC:<runId>`。不同局分開備份，舊備份不覆蓋；備份失敗會阻止寫回，不強行覆蓋原檔。
- 讀取相同定義不反覆增加修訂、不反覆寫檔。損壞存檔不在同步函式內默默覆蓋。
- 同步對象是應用程式目前提供的精靈資料池，包含目前生效的內建覆寫；不是自行去 GitHub 下載定義，也不把舊版自訂資料當官方資料強改。
