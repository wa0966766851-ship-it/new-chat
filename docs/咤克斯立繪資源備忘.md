| 恐懼的化身·咤克斯 | 5010 | 僅保留作為 Seer 資源參考；本機 5010 圖片端點不存在 |

5010 是靜態美術資源 ID，不代表標準精靈資料 API 有相同編號的精靈資料列。這個執行環境的本機 `/seer/head/5010.png` 與 `/seer/body/5010.png` 都回 404，故恐懼化身改用下方使用者提供的圖片做本機美術，不依賴遠端取圖；Seer ID 覆寫仍保留作為資源來源紀錄。

專案內找到的原始 JPG 為 `pet/恐懼的化身·咤克斯.jpg`（840×1024）。全身圖 PNG 由此圖做去黑底處理；與 JPG 合成比對後主體一致。JPG 不會被 `/seer/{head|body}/<id>.png` 路由直接讀取，因此戰鬥改用 `public/elf-art` 的本機圖。頭像來源維持原樣，不替換。

本機美術檔：

- 全身立繪：`public/elf-art/zhakesi_fear_body.png`
- 頭像裁切：`public/elf-art/zhakesi_fear_head.png`（保留舊檔；目前不接管頭像顯示）
- 全身立繪只對戰鬥 body 使用自訂 JPG 衍生 PNG；避免更動頭像來源。

## 戰鬥版面比例備註

- 恐懼化身與湮滅之主使用同一組大型立繪 footprint，確保 P1、P2 尺寸對稱。
- P1 朝右、P2 朝左。經本機 Seer 全身圖縮圖核對，官方戰鬥素材多數原生朝左；已在 `BATTLE_SPRITE_FACING` 逐隻標註目前名冊方向，正面素材標為 `front`，未確認的自訂路徑維持原方向。
- 未特別覆寫的精靈依身高公分使用次線性縮放（180 cm 為基準，倍率限制 0.68–1.5）；超過 10,000 的哨兵身高不當作真實體型。
- 立繪所在場景層低於精靈資訊卡、回合資訊和下方操作區；圖片可延伸到場景範圍外，但 UI 資訊仍在上層。
- 這兩隻資料中的身高是極大的特殊數字，不是可直接對應畫面像素的真實身高。通用身高公式會把它們一起夾到縮放上限，故採用明確的戰鬥立繪設定，不用該身高值決定咤克斯畫面尺寸。
- 一般精靈若要依體型縮放，建議新增獨立的立繪比例欄位或小型覆寫表，並以全身圖非透明像素的實際包圍框校準；只看身高或 PNG 畫布尺寸都會被透明留白誤導。
