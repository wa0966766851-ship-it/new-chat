## 2. 參考設計：拾光行記的設計語言

來源：`/mnt/user-data/uploads/拾光行記-互動網頁/`（README、index.html 約 2000 行單檔 Canvas 2D、shots）。

### 2.1 一眼可辨的八件事

1. 配色極少：紙底 `#F2EDE4`、墨藍 `#16307A`、鈷藍 `#1F4FD8`、淡鈷 `#7C9BE8`，唯一暖橙 `#E8622B` 只給套印錯位與標記（面積 < 3%）。無漸層、無發光、無金色。
2. 手繪筆法 `sk` 模組，全站沒有一條直接 `stroke()` 的直線或完美圓：
   - `ring`：半徑疊兩層正弦起伏，收筆越過起點 8°至15°。
   - `rule`：中段微拱，兩端衝出 3至6px。
   - `brush`：沿法線算寬度 0→w→0 的閉合輪廓。
   - `blade`／`sparkle`：光刃、星芒。
3. 套印錯位 `ink()`：同一條線偏移 (1.15, 0.95)px 再描一遍，透明度 0.4。
4. 線寬跟景深 `DW(d)`：遠 0.6、中 0.85、近 1.15、最近 1.55；遠景細如髮絲，近景像馬克筆。
5. 景深分層與視差：每個場景由遠到近 4 至 5 層，指標移動時各層位移不同；切章節時各層由遠而近依序拼入。
6. 圖版構成：人員圖版＝遠景網點、中景星座與故障條、拼貼車票花枝、近景職業圖標與星級色弧；版式 A（紙底拼貼）與 B（鈷藍反相）可切換；背後放巨大淡色英文名當浮水印。
7. 導覽：左下章節列（短線＋編號＋章名，目前章節線變長變藍）、右上工具鈕（圖紙 B、聲音 M、全屏 F、重置）、底部置中提示一行、頂左品牌。
8. 確定性：所有圖形由 `rng(seed)` 驅動，零 `Math.random`；同一個 t 重畫像素一致。

### 2.2 互動手法

| 手法 | 做法 |
|---|---|
| 拖曳視差 | 拖越快，模糊與傾斜越強，並驅動背後序列，往回拖倒放 |
| 長按測繪 | 長按空白發脈衝，量到最近節點的距離 |
| 雙擊連線 | 雙擊節點標點，繞回起點自動閉合成面積 |
| 吸附 | 落點靠近隱藏點位會吸附，以引線相連並顯示間距 |
| 圖紙模式 B | 實心圓盤褪成線框，射線流動，浮現尺寸標注；也可由集齊字母觸發 |
| 懸停 | 節點轉出旋轉鎖定圈 |
| 動作節制 | `prefers-reduced-motion` 下 transition 全部 0.01ms |

### 2.3 現有程式離這個目標有多遠

| 項目 | 狀態 |
|---|---|
| `ring`／`rule`／`brush`／`blade`／`sparkle`／`makeHalftone` | 已移植（`src/design/sketchStroke.ts`），測試過 |
| `ink()` 套印、`DW()` 景深線寬 | 未移植 |
| 隨機源 | 移植版用 xorshift，原版用 mulberry32；同 seed 圖形不同，需決定是否對齊（見 §7 問題 5） |
| 景深視差 | `PaperDestinyBackdrop` 只有慢速自轉，沒有指標視差、沒有分層切換 |
| 圖版、章節導覽、圖紙模式 | 無 |

**手繪筆法的實作分工**

| 層 | 技術 | 內容 | 為什麼 |
|---|---|---|---|
| L0 紙底 | CSS `background-color` ＋ 一張離屏 Canvas 紙纖維（2400 條淡線，seed 固定）快取成 dataURL 或 `ImageBitmap` | 全頁 | 只畫一次 |
| L1 遠景 | 一個全頁 Canvas 2D（`PaperDestinyBackdrop` 擴充） | 半調圓盤、三環、12 射線、星芒 | 會動；只在需要時重繪 |
| L2 圖版 | 每張卡一個行內 SVG，path 由 `sketchStroke` 產生並以 `(seed,w,h)` 為鍵 memo | 外框、半調圓盤、星座線、分級章 | 要可點、可聚焦、可被無障礙讀取；24 張 × 約 4 path，數量小 |
| L3 前景 | 絕對定位 SVG | 封印叉、首發圈、飛入路徑 | 事件驅動，動畫時間短 |
| L4 UI | DOM | 按鈕、章節列、文字 | 無障礙與輸入法 |

**必補的筆法函式（`src/design/sketchStroke.ts`）**：`ink(d)`（套印錯位，SVG 以 `<use>` 偏移 (1.15,0.95) 與 0.4 透明度實作）、`DW(depth)`（景深線寬）、`stamp()`（手繪方章，由 `rule` 四條組成，角落衝出）、`hatch()`（斜線底紋，給 C 級）、`cross()`（封印叉，兩條 `brush`）。全部沿用 `rng(seed)`；seed 由 `instanceId` 的雜湊產生，同一張卡每次畫出來一樣，翻牌前後不抖。

**景深分層與視差**：L0 不動；L1 位移 ±6px、L2 ±14px、L3 ±22px（桌機以指標位置、手機以觸控拖曳；**不用陀螺儀**）。線寬走 `DW`：L1 0.6、L2 0.85 至 1.15、L3 1.55。換章節時各層由遠而近依序淡入（延遲 0／80／160／240ms）。

### 5.5 互動如何對應玩法

| 參考的手法 | 命運之輪裡的用法 |
|---|---|
| 長按測繪 | 長按卡片 350ms ＝「預覽」：不開詳情，顯示六維種族值細線圖與屬性克制（取代桌機 hover，手機也可用） |
| 雙擊連線 | 編隊：雙擊出戰格設首發（手繪圈）；禁選：雙擊 ＝ 直接封（單擊仍可，雙擊只是快捷）。不使用「連線成面積」玩法 |
| 圖紙模式 B | 全域切換：圖版褪成線框，顯示尺寸標注式資訊——六維數值、分級判定來源（名單／文本／種族值）、PP、先制、攔截說明。**所有「說明文字」集中在這一層**，平時畫面保持乾淨 |
| 版式 A／B | A：紙底拼貼；B：鈷藍反相。工具列切換全域；詳情圖版可單張翻面。不影響資料 |
| 確定性種子 | 抽卡由 `seed` 決定（已有 `rng` 參數）：顯示短碼，可輸入重現同一組；PVP 雙方用同一 seed 的兩段（`p1`／`p2`）保證公平。測試可固定 seed 對照截圖 |
| 抽卡儀式 | 12 射線依序畫出 → 12 個點落位 → 每點展開成卡背；分級揭示時，該卡的分級章「蓋」上去（S：暖橙套印錯位 120ms；其餘 80ms）。全程可按空白鍵或 [跳過] |
| 分級揭示順序 | 全翻時由 C → B → A → S 依序（戲劇性遞增），單翻照點擊 |
| 吸附 | Pick 時卡片拖到格位附近 24px 內吸附，以引線相連 |
