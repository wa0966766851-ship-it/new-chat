## 三類顯示模式 × 回合分隔（你要的核心）

### 設計：顯示端分級，產生端不動

關鍵決策：不改 612 處產生端（會炸全部語意測試），在顯示端加「歸類 + 詳略分級」層。
每條 log 用規則歸到三級：

| 級別 | 內容 | 規則 |
|---|---|---|
| A-主行動 | 【XXX】使用了【技能】！/ 進行了 n 次額外行動 / 切換精靈 / 使用藥劑 | 精確匹配主模板（battleEngine 唯一產生點） |
| B-傷害類 | 造成/受到/恢復/吸取/擊敗 等數值行 | 傷害動詞 + 傷害 emoji |
| C-效果觸發 | 其餘全部（效果細節） | 預設歸此 |

三種顯示模式（UI 切換）：
1. 簡潔模式：只顯 A——每回合一行「【XXX】使用了【XXXX】」與「【XXX】進行了 n 次額外行動」
2. 傷害模式：A + B（主行動 + 傷害數值）
3. 完整模式：現狀（A+B+C）

### 文案模板修正（同步）

- 主行動模板「【XXX】使用了【XXXX】！」已符合要求，保留。
- 額外行動「⚡【額外行動】label」→ 顯示端合併為「【XXX】進行了 n 次額外行動」。
- 全程繁體中文：產生端本來就是繁中；奧丁符文名（特殊精靈專有名）依指示保留；
  排查 log 模板殘留簡體字（攻击/毕/当）統一為繁體。

## 額外優化建議（按性價比）

1. 回合摘要頭：回合分隔行顯示該回合總傷害/擊敗（從 ledger 算）
2. 精靈過濾：點精靈名只看其相關行（fog 保留）
3. 傷害量級分色：B 級行按傷害量高亮（logTone 現只按類型）
4. 自動跟隨：底頁時新訊息跟隨、翻歷史時凍結
5. 複製選項：copyLogs 加「只複製簡潔版」
6. 效能：分級後簡潔模式渲染量天然減 70%
