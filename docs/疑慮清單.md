## A. 第二批 5001/5002（本次處理）

### A1. 5001 悲歌.索比拉特

- [技能] `影之牢籠`：「以令下次被擊敗時黯痕回合數+1」
  - 疑慮：描述以「以」開頭，疑似承接上一句「消耗自身全部體力」的代價語，觸發時點不明（使用時立即生效 vs 下次被擊敗時結算）。
  - 保留做法：舊 SOBIRAT_SKILLS 已有 `sobiratScarBonus+1` 邏輯，積木側新增 custom 對齊，不刪除 handler。
- [技能] `影之牢籠`：「若對手因此被擊敗則自身保留1點體力」
  - 疑慮：「因此」指 300 固定傷害這一擊，屬 after_hit 擊殺條件，與通用 survive 不同。
  - 保留做法：custom 掛 after_hit kill 條件，handler 原邏輯保留。
- [技能] `幽冥噬魂`：「3回合內自身使用攻擊技能時若攻擊技能無效則消除對手回合類效果」
  - 疑慮：「攻擊技能無效」的判定在積木側只有 on_invalid 節點，與 timed 包裝的互動未驗證。
  - 保留做法：custom 用 self_invalid 追擊計時器（仿深潛者盛宴），舊 handler 的 sobiratDispelOnFailedTurns 保留。
- [魂印] 黯痕 5 句（傷害上限1點、無視改減半、禁附加異常等）
  - 疑慮：黯痕是跨精靈印記，含傷害上限、禁異常、受擊翻倍三重效果，積木 mark 系統尚未支援「傷害上限+禁異常」複合。
  - 保留做法：維持 handler（handleSobiratSoulMark）為準，積木不登記 SOUL_MODE，僅做解析覆蓋。

### A2. 5002 帝皇之盾

- [技能] `帝永壁令`：「4回合內每回合使用技能後恢復自身最大體力1/3，並將恢復量的50%轉化為護盾」
  - 疑慮：「每回合使用技能後」是 self_skill 觸發還是 round_end 觸發，舊 handler 走 AFTER_ACTION，與積木 timed 語義有差。
  - 保留做法：custom 用 timed(self_skill) 對齊，舊 IMPERIAL_SHIELD_SKILLS 保留。
- [技能] `盾碎同歸`：「消耗自身全部護盾值，每消耗100點護盾值令對手隨機1個技能PP歸零」
  - 疑慮：消耗量是快照還是逐次扣減，隨機 PP 歸零是否可重複命中同一招。
  - 保留做法：custom 快照護盾後清零，按 floor(shield/100) 執行 pp_zero_random，舊 handler 保留。
- [技能] `盾碎同歸`：「消耗護盾值為0時自身全屬性+2且下回合先制+3」
  - 疑慮：條件是使用前護盾為 0，還是消耗後為 0，兩者語義不同。
  - 保留做法：按「使用前快照為 0」實作（與舊 handler 一致），custom 對齊。
- [魂印] 守護印記 2 句（減傷25%+每層10%最高55%）
  - 疑慮：層數如何疊加描述未寫，舊 handler 用 nextElfShield 快照，與積木 mark 計數語義不同。
  - 保留做法：維持 handler 為準，不登記 SOUL_MODE。
