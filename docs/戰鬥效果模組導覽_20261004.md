# 戰鬥效果模組導覽

本輪採職責整理，不搬動整個專案目錄、不改素材、不重新生成描述。其他AI既有修改保留。

## 規則與執行分層

| 職責 | 檔案 | 使用方式 |
|---|---|---|
| 原始效果分類 | `src/data/effectClassificationCatalog.ts` | 攻擊免疫是命中階段；抵擋／免疫傷害／轉化傷害是傷害階段，不可混用 |
| 攻擊免疫判定 | `src/battle/attackImmunity.ts` | 決定攻擊是否未命中；被貫穿不消耗一次免疫 |
| 攻擊傷害防護貫穿 | `src/battle/attackDefense.ts` | 個體綁定、攻擊傷害限定的block／conversion／limit／shield參數；不抹掉正常減傷 |
| 型別與盾罩 | `src/battle/damageSemantics.ts` | 護盾承受技能傷害、護罩承受固定／百分比；真傷穿透兩者 |
| 持續增減傷 | `src/battle/damageGates.ts` | 持有者、期限、分類與條件過濾 |
| 減傷政策與終段門檻 | `src/battle/damageReduction.ts` | 受到／造成分流、99%特例、比例衰減、多來源疊加；不混用抵擋與護盾 |
| 專屬特質數值修正 | `src/battle/advancedDamageModifiers.ts` | 投石者四技能石的攻擊增減傷、自身黯痕輸出限制 |
| 當前體力限制 | `src/battle/hpCeiling.ts` | 傷害前快照、來源綁定，限制當前體力而不修改maxHp |
| 帝辛天陣生命週期 | `src/effects/dixinFormation.ts` | 開啟、期限、點數減免、關閉代價；不在核心添加精靈名稱分支 |
| 計時受擊／恢復反應 | `src/battle/timedReactions.ts` | 受攻擊觸發真傷、恢復量乘區、個體登場歷史 |
| 非正體力存活 | `src/battle/survivalRules.ts` | 存活條件與傷害免疫分開；無視傷害防護不等於取消六刃／雷伊的存活規則 |
| 結算回饋 | `src/battle/settlementReceipt.ts` | 名目量、盾罩承受、实际扣血、恢復請求／實際恢復不可混用 |
| API與共同流程 | `src/battle/contextBuilders.ts`、`src/components/BattleScreen.tsx` | 只讀通用參數，不添加精靈名稱分支 |

## 蟲后檔案依職責排列

1. 原文：`elf_source_files/elf_files/5018_蟲后奧佩婭.txt`。
2. 魂印生命週期：`src/effects/opeiaRegistry.ts`。登場六維、混沌判定、下場還原、技能PP／異常等。
3. 持續技能：`src/effects/opeiaTimedEffects.ts`。蟲群庇護、蟲后之冠及期限。
4. 攻擊技能：`src/effects/opeiaAttackSkills.ts`。噬心毒蝕、鏽腑喰心、主傷害後結算。
5. 對應驗收：`opeiaFlow`（魂印流程）、`opeiaRemaining`（持續效果）、`opeiaAttackSkills`（攻擊技能）、`attackDefense`（共同防護與混沌貫穿）的語意測試。

## 維護規則

- 先確認TXT中的主客體、傷害類型、時點、期限和下場保留；有疑義留待確認，不把普通減傷自動當免疫。
- 防護handler收到 `DamageComputation.attackDefenseBypass`，在抵擋／轉化的分支前檢查；不整個跳過防守方handler，以免連正常減傷／其他被動一起刪掉。
- 被貫穿不消耗防護次數、不積存抵擋量、不觸發「抵擋成功」反擊或恢復。
- 傷害上限可跳過，但死亡条件／免死與神降負體力下限仍正常判定。
- 第五技能、魂印、積木的持續效果不要移回BattleScreen硬編碼；新增語意測試納入完整測試鏈。
- 修復狀態與仍未驗證的組合寫入 `共同機制與實裝修復計畫_20261004.md`，此導覽不是完成率報告。

第五批減傷入口、缺碼補建及驗收邊界見 `減傷機制修復與驗收_20261004.md`。新增普通減傷須呼叫共用政策，不再直接增加`decreasePercent`或把所有傷害乘區當成同一類減傷。
