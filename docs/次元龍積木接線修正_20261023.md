# 次元龍積木接線修正（2026-10-23）

## 正式通道

正式資料 `5021` 的魂印與五招採 effectMode=kit。技能入口以 effectRoute(..., true)=kit 驗證，即使相容用的舊 handler 仍存在，也優先執行可編輯積木。舊 registry 不作為本輪修正入口。

- 來源：migratedDimensionalDragonSkillKits.ts、migratedDimensionalWangshiKit.ts、migratedFinalMarsLanDragonKits.ts。
- 資料封裝：pack_reviewed_kits.ts → reviewedKits.compressed.json／reviewedKits.homepage.json；封裝前完整參數深比較。
- 執行：BattleSkillRegistry／魂印生命週期 → effect_sequence → 通用 runtime operations。
- 追加技能傷害：dmg.appendToAttack → applySkillTypeDamage 獨立計算克制與增減傷 → attachedAttackDamage 按行動、施加者、目標識別 → 主公式結果相加 → 同一次主攻擊扣血。屬性技能直接走技能傷害管道。保底仍用原本 floor 管道。

## 本輪修正

1. 告命詩途先制條件改查正式 actionPriorityThisTurn，不用詩章數代替。
2. 敕界歸元的攻擊後封屬依下2回合起算。告命詩途按雙方每個滿PP技能乘2；先制、易傷、禁切換依下2回合期限。
3. 告命詩途、神懺福音之章、魂印10篇追加技能傷害支援與攻擊合併。
4. 敕界歸元／告命詩途直接取得詩章時保存每篇體力上限快照，移除人為999篇上限。
5. 遺典.妄世律裁：每篇增傷20%、每篇100真傷、對方每個滿PP技能的20%當前體力傷害，均補回計數。
6. 第五技能龍魂：按雙方體力差值70%計真傷，雙方每個滿PP技能翻倍7次；攻擊回血接通通用vampire，不再依賴舊魂印handler消費旗標。
