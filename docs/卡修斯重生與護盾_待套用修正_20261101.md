## 三、要修的三個問題

### 問題 1：重生次數被限制成整場一次

**現況**（`src/engine/battleEngine.ts:678`）：
```ts
fCtx.updateAnyElf(targetSide, holder, {
  teamRules: { ...(持有者原 teamRules), excessTrueRebirth: false }
} as any);
```

重生一次後把旗標關掉，之後永久不再重生。

**應改為**：不寫 `excessTrueRebirth: false`，讓重生可重複觸發。

```ts
// 移除該行中的 excessTrueRebirth: false
// 若該 updateAnyElf 僅為此目的，整行刪除
```

**依據**：使用者裁定「100%重生1次」= 每次滿足條件都重生（解讀 A），無總次數上限。

**連帶**：`teamPassiveRules.ts:50` 的註解「重生後消耗持有者的 1 次機會」需同步修改，`rebirthHolderOf` 若只為消耗旗標而存在，可保留但語意改成「找出生效持有者」。

---

### 問題 2：其他精靈觸發不了重生

**現況**（`src/battle/teamPassiveRules.ts:17`）：
```ts
const alive = (e: any) => !!e && !e.isVanished && !e.isExtra && Number(e.currentHp) > 0;
```

`teamRulesOf`（第 24 行）只讀 `alive(e)` 的 `teamRules`。

**問題**：重生旗標寫在卡修斯自己身上。卡修斯一旦死亡（`currentHp === 0`），`alive()` 回 `false`，旗標被跳過 → 隊友永遠無法觸發重生。

**應改為**：重生與護盾規則屬於「出戰背包被動」，持有者死亡後仍應對隊友生效。

建議做法（二選一）：

**方案 A（推薦）**：把 `excessTrueRebirth` / `excessIntercept` / `shieldDeductionRatio` 的讀取改成不看 `alive`，只看「該精靈是否在隊伍中且未被移除」：
```ts
const inTeam = (e: any) => !!e && !e.isVanished && !e.isExtra;
for (const e of team || []) {
  const r = inTeam(e) ? e.teamRules : undefined;
  ...
}
```
但需確認：`isVanished` 是否代表「永久移除」。若卡修斯死亡只是 `currentHp = 0` 而非 `isVanished`，這樣改即可。

**方案 B**：把旗標提升為隊伍級狀態（`getPlayerState('teamExcessRebirth')`），不綁個體。

**驗證**：卡修斯死亡後，隊友受到致死真實傷害且傷害 > 當前護盾，應觸發重生。

---

### 問題 3：「當前護盾值」的取值時機

**現況**（`src/engine/battleEngine.ts:674`）：
```ts
isLethalExcessTrue(effectiveAmount, target.shield || 0, hpBefore)
```

`target.shield` 是該次傷害結算前的快照。

**已裁定（2026-11-01）**：取「受到該次傷害前的當前值」，現況 `target.shield` 正確，**不需修改**。原問題描述保留如下供追溯：

- **解讀 i（現況）**：該次傷害打出時的護盾值（消耗前）
- **解讀 ii**：扣除本階段已消耗後的護盾值（消耗後）

**使用者原話**：「當前值也要看是什麼時候的當前值，如果是消耗前的就應該...改成消耗後，或者是該傷害打出時對應的護盾值...」

**注意**：護盾消耗發生在 `battle_phase_end`（階段結束），而傷害判定在階段內。所以：
- 同一階段內多次受擊 → 都用同一個「消耗前」護盾值判定
- 下次階段開始前才扣除

**結論：不需修改。**
