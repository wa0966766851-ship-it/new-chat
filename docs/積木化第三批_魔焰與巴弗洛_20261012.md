## 共用缺口與實際修正

1. 原執行器有能力值傷害，合約卻只准體力／護盾基數。新增共用 `damageBases.ts` 明確列出可用面板欄位，校驗與執行使用同一表；未知名稱仍拒絕。此處不冒充主技能傷害公式的有效雙攻，也不偷偷加入能力等級倍率。
2. 異常轉化原先整個清空effects及狀態。現在只移除真正被轉化的非BOSS異常，保留BOSS狀態、未知增益及印記，再走既有免疫檢查附加新異常。合約要求單一目標、名稱、期限；文本未寫期限時明確生成3回合，讓自訂描述也能蒸餾成相同積木。
3. 正式後手測試找到「3回合內」被多算成4回合。`timed.from`與事件種類拆開：當回合起算不因先後手補償；下N回合維持延後啟動。沒有把全部使用級、命中級混成同一節點。
4. 唯讀積木對沒有人工標籤的動作，顯示目標、回合、數值、傷害種類與遞增上限；保留人工命名。只是顯示投影，不改儲存label／PRD鍵。複雜巢狀動作在畫布仍有JSON參數編輯，尚不是所有欄位都改成獨立圖形插槽。
