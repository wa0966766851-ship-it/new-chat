## 一、動畫

| 項目 | 做法 | 位置 |
|---|---|---|
| 額外行動只多播一次 | 額外行動節點內的紅字先收集；節點結束時等主紅字播完 → 播一次出招動畫 → 一筆合併紅字（標「額外行動」）。不論幾次都一樣；沒有額外行動不播空段。額外行動造成的粉／白傷仍留到回合末。 | `presentation.ts` beginExtra／endExtra；`BattleScreen.tsx` finishExtraPresentation（出手結束與回合末兩處） |
| 自訂開關 | 設定 → 戰鬥介面 →「動畫播放」：出招動畫、技能傷害、額外行動、吃藥回血、回合末結算。只影響播放；關掉的通道不出浮字，但體力條照常對齊。 | `src/battle/animationSettings.ts`、`ControlHub.tsx` |
| 播放順序 | 維持你定的：出招紅字即時 → 吃藥綠字即時 → 額外行動一次 → 回合末粉 → 綠 → 白。唯一例外：致命那一下會先把累積的數字依原序播完，避免看成先死再回血。 | `presentation.ts` |

註：你電腦上原本有一個未接線的 `animationSettings.ts`（前一個 AI 斷線前留下的半成品，沒有任何地方引用），已用這版覆蓋。

中央大字（lastActionInfo）仍是 null，等你決定要放「行動摘要」還是「最近數值」。

## 二、P0 死路（寫了沒接）

| 精靈／技能 | 修正 |
|---|---|
| 龍錄天鋒・鋒毫浸血雨 | 下 1 回合第一次攻擊命中時扣自身目前體力 1/2，造成等量百分比傷害；施放當回合不觸發，只觸發一次。 |
| 莫伊萊・陰陽三合 | 改用通用逐擊流程：一回合 5～10 次，每次實際命中各自判定 20% 附加 100 固定傷害。 |
| 莫伊萊・恆·蒼穹斗轉 | 攻擊結算後用本次累計攻擊傷害判 300：高於 → 免疫下一次異常（次數型）；低於 → 下 2 回合攻擊必定致命一擊（原本寫了沒人讀）。25% 百分比傷害被免疫時轉真實傷害。 |
| 莫伊萊・日月安屬反擊 | 抵擋時直接取抵擋前的本次攻擊傷害（攻擊方增減傷已算入），對攻擊者附加 100% 百分比傷害，只觸發一次。 |
| 龍之治癒・真龍 | 喚醒後每次使用技能排入一個額外行動，額外使用 4 次（不扣 PP、不再連鎖）；攻擊技能走技能傷害公式，屬性技能每條龍 150 龍系傷害。 |
| 龍之治癒・挨打要立正 | 屬性剝離：轉為普通系、每剝一種附加 1 種隨機異常、任一次失敗 → 龍魂印記 +1；已剝離不重複；下場自動恢復原屬性。 |
| 龍之治癒・幽魔相嘯 | 技能無效時龍魂印記 +1。 |

新精靈描述標記與專有名詞的確認表：`docs/新精靈描述標記與名詞確認_20261003.md`。
