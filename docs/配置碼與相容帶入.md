# 配置碼與相容帶入

入口：設定 →「存檔與配置」。舊版設定可在「系統」找到同一個面板。

## 分享與使用

1. 在來源端按「產生配置碼」，再複製或下載 `.seerconfig` 檔案。內容包含精靈、練度、技能、雙方陣容、背包預設與配裝。
2. 在接收端貼上配置碼或讀取檔案，按「預覽」。此時不更動存檔。
3. 檢查可帶入內容與「相容性說明與略過項目」，回到首頁後按「套用並重新載入」。
4. 需要撤回時，按「復原上次套用」。只保留最近一次套用前的還原點，儲存在目前網站位址的瀏覽器資料庫。清除網站資料也會清除這個還原點。

音樂、背景、動畫、計時器等設定需另外勾選，預設不分享。肉鴿進度及其獨立種子始終不在配置碼內；帳號、API 金鑰、連線身分、對戰記錄也不分享。

配置碼內含實際的壓縮資料，不依賴伺服器，也不是可用短數字重建任意配置的隨機種子。內嵌圖片較多時，建議用檔案分享。

## 相容性

來源版本較新不會直接拒絕整份配置。能辨識的內容逐項檢查後帶入；不支援的欄位、裝備、皮膚或技能會略過，保留接收端原本的選擇。

- 不支援的積木會使該技能整項略過，不會刪掉部分效果後假裝已完整匯入。
- 自訂精靈核心資料或圖紙不相容時，略過該精靈；其他相容精靈仍能帶入。
- 陣容缺少部分成員時，保留可用成員的順序重新排列：前六格出戰，其餘待命；首發不在可用名單時改用第一隻。預覽會說明。
- 某組陣容全部不相容時，保留原陣容；整份都沒有可用內容時不套用。
- 相同精靈識別碼更新相容的配置，其他原有精靈與背包預設保留。
- 內建精靈以接收端現有定義為基礎。相容性檢查可確認資料格式與已知積木，不能保證不同版本的戰鬥平衡與所有機制完全相同。
- 已支援舊版 JSON 本機備份與桌面存檔備份，只擷取允許分享的項目。無法解析的外層編碼、檔案損壞及錯誤密碼不能安全讀取，會停止且不修改存檔。

預覽後若本機相關資料已改變，需重新預覽。套用前先建立還原點；寫入失敗會嘗試恢復原值。桌面版另會等待磁碟同步完成再重新載入，避免重開後又讀回舊資料。

## 選填密碼

不填密碼產生 `SCFG1` 壓縮配置碼，內容不是加密。SHA-256 用於檢查資料完整性，不是來源身分認證。

填入密碼會產生 `SCFGE1`：採用 AES-GCM 256 位元、隨機鹽與初始向量，透過 PBKDF2-SHA256（210,000 次）導出密鑰。其他電腦可用同一密碼讀取，不綁定裝置。密碼不存入配置或本機存檔，遺失後無法恢復。加密功能需要桌面版、localhost 或 HTTPS 提供的瀏覽器加密功能。

## 維護與檢查

`npm run test:player-config` 驗證混合相容匯入、舊檔、正式雙方陣容載入、加密、失敗恢復、桌面同步及實際瀏覽器操作。

格式、欄位相容檢查與套用交易分別位於 `src/playerConfig/codec.ts`、`model.ts`、`transaction.ts`。新增分享範圍時維持明確允許清單，增加對應格式驗證與不相容部分保留本機資料的案例；不加入私人資料或肉鴿進度。
