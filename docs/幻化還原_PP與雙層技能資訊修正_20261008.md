本輪只處理幻化還原、取得效果來源、PP 與敵我顯示。既有未提交修改保留；未提交、推送或重新打包 EXE。

## 使用者確認的語意

| 觸發 | 條件 | 目標 | 行為 |
|---|---|---|---|
| 開始幻化 | 有合法目標 | 自身 | 在自身能力基底上加目標當下六維；不把目標改回原始能力 |
| 使用技能 | 幻化仍有效，固有未失效 | 原技能槽 | 選擇、扣 PP 仍屬於原槽；實際使用目標同槽技能 |
| 轉化後行動 | 原技能固有條款有效 | 自身／原文指定對象 | 保留原先制、必中與變思遷憶；不重跑原技能附加效果 |
| 解除幻化／下場 | 正在幻化 | 原持有者 | 恢復自身形態與能力層，解除借用加成及暫時 PP 上限，不把能力硬扣至 1 |
| 查看己方技能 | 正在幻化 | 己方檢視 | 主欄保留原技能名稱與屬性圖標，另列轉化技能及資訊 |
| 查看敵方幻化者 | 非隱匿 | 敵方檢視 | 顯示幻化對象外觀、屬性與效果定義；不改真正戰鬥屬性，不洩漏原槽資訊 |

對照：`elf_source_files/elf_files/星核寰宇·艾斯菲亞.txt` 與 `星軌重構·艾斯菲格.txt` 的幻化／■固有效果段落，以及本輪使用者對 UI 的最新要求。

## 已修根因

1. 舊解除流程直接以「當下面板－借用面板」恢復。如果中途整份面板被重算回自身基底，解除會再扣一次，最後被下限保護壓成 1。新流程獨立記錄自身與投影能力，正常寫入追蹤差量；完整基底回寫不再被當成自身永久下降。
2. `pp` 與歷史 `currentPp` 不同步：補藥只改其中一個，後续能力恢復又從舊欄位讀取。正式寫入、恢復與扣除入口現在同步；讀值以 `pp` 為準。
3. 無為龍者取得效果的 PP 限制判定只查自身，轉化後又按新名稱尋找原技能，找不到原槽。現改查兩個效果來源，並以技能槽記錄／交換 PP；成功及失敗分支皆使用原槽與動態 PP 上限。
4. 原特性被幻化目標覆蓋。現保留原定義，取得定義另列來源；通用能力與已有普通特質管線讀兩份來源。
5. UI 原先只換外觀，不一致地使用真實屬性、真實效果介紹。現改為專用檢視投影，己方原槽與轉化資訊並列；敵方投影不混入己方原固有描述。
