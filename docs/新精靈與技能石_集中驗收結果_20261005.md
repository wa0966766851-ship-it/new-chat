集中驗收揭露後已修正：

1. SS 半傷 timer 寫了引擎不接受的 `all` 類型，改為明確 `non_true`；真傷不減半。
2. 技能石透過 `poisoned` 加中毒卻留下英語欄位，統一異常入口別名；歷史 `frozen` 為石化，`ice_sealed` 才是會衍化凍傷的冰封。
3. 四種同屬性技能石不能冒充四種不同屬性以取得神話；開局免弱化亦不依賴晚到的可視狀態。
4. 思維干涉原始反饋快照取太早，改為後续普通增減傷完成、自己減半前取值。
5. 星護必中後PP歸1原先只能向下限縮，修為0也可調整至1；歸零恢復只針對实际耗盡槽。
6. 同名技能扣PP／幻化選錯槽：明確槽位，無法唯一辨識則不猜。
7. 新精靈抵擋／轉體力漏讀無視旗標，修正分類貫穿且不消費未成功觸發的次數。
8. 埒殘銜闕50%吸取應是比例／百分比傷害，不是固定傷害；禁止同來源反應遞迴。
9. 溢出恢復以最終恢復結算量減實際增加量計，不用尚未套用恢復限制的請求量。
10. 場下四類傷害、致死保留1點及摩哥斯驅逐均驗證不污染真正的在場者；驅逐不派發文本禁止的普通換人／登場鉤子。

連擊測試的舊「逐擊」命名也已改為「連擊附帶次數」，重新執行該整合測試通過。只改測試標示，不改連擊結算機制；完整測試是在此命名整理前通過，整理後另重跑受影響測試。

## 4. 前端大小與效能界線

最大前端區塊 `codexRegistry` 為491.33 kB；戰鬥效果登記440.81 kB；積木資料庫420.53 kB；Blockly分段最大123.05 kB。首頁初始 JavaScript 889.22 kB，通過專案950 kB預算。

描述原文打包144,389位元組 → 41,082位元組，保留原始資料並做解壓往返檢查。沒有改高500 kB警告門檻，也沒有以gzip傳輸大小冒充Vite原始區塊大小。

區塊變小、按需載入及測試通過不代表低階手機長時間戰鬥絕對流暢。本批未完成實體低階手機 FPS／記憶體與正式長任務量測。
