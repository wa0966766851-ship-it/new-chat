# 連擊公式統一、傷害演出、星際探索重製「星蝕回廊」（2026-10-03 第五輪）

驗證：`npm run lint`、`npm test`（新增 comboFormula、eclipseEngine、星蝕回廊元件流程）、`npm run build` 全過；瀏覽器實際走完 啟程 → 選秀 → 地圖 → 事件／商會／星爐／祭壇 → 迎戰 → 托管打贏 → 返回回廊 → 戰利品。

## 一、連擊＝變威力（官方公式）

- 傷害公式改為逐步取整：`[(等級×0.4+2)×威力×攻÷防÷50+2]×本系×克制` → 取整 → `×浮動(217~255)/255` → 取整 → `×暴擊` → 取整 → 套裝／稱號／刻印 → `×連擊次數`。方括號內不拆分。
  - 驗證冰王例：攻 602、譜尼物防 393、威力 1、×1.5×0.5、90 連擊 → 浮動 217～254 為 90、255 為 180。
- 連擊不是額外行動：只算一次傷害、一次紅字（標「N連擊」）、一次動畫；每擊附帶的判定仍逐擊結算（攻擊方被反擊致死就停）。
- 連擊屬變威力：技能使用時的效果（雙方強化／弱化、連擊次數、每擊強化）全部先結算，再以結算後的能力等級算傷害。
  - 魯斯王【浪打千擊】5～10 擊、每擊 20% 強化：改為傷害前以 PRD 擲完再計算。
  - 無序三刃：「每有 1 點 PP 則連擊 +1／+3」原本只寫日誌沒生效，已接上（以使用前 PP 計，六刃碎界斷為 1+3×PP）。
- 待確認：【靈光之怒】（譜尼）原文「對手能力等級越高威力越大（內置公式等級6:18）」目前以 40×等級 的固定傷害替代，公式不明，請提供。

## 三、星際探索 → 星蝕回廊（全面重製）

### 玩法
- 六章，每章隨機路網：路途 9～13 欄、5～6 軌、5～7 條路徑合流加支線，同種子可重現；「？」節點真身生成時即決定。
- 節點：遭遇、夢魘（精英）、王座、異兆、？、瞳孔商會、星爐、寶匣、蝕之祭壇。遠處欄位是迷霧。
- 蝕度（0～100+）：每步 +3，夢魘 +3；眉月敵人 +10%、半蝕精英多詞綴＋獎勵 +25%、盈蝕全員詞綴、全蝕每步失 5% 體力但獎勵 +50%。換章 −15。
- 敵人：體力 一般 ×2.5／夢魘 ×4／王座 ×7 起跳，每章再加（王座第六章再 ×1.3），並且至少為我方最高體力的 1.5／2.5／4 倍（每章 +0.25），避免我方帶高體力精靈時反被壓過；其他能力 ×1.15 起，每章 +0.15。
- 藥劑：對戰中「道具」頁顯示剩餘次數，用盡後其他道具鎖定；「特殊」類道具不計次、不鎖定（保留）。只影響星際探索。恢復手段：商會購買、星爐修復 +1、夢魘必得 +1、一般戰鬥 25%、事件、藥劑腰帶 +2、藥師的提燈（每章 +2）、換章補到至少 3。詞綴 8 種（狂暴、堅甲、再生、咒怨、汲魂、巨化、迅捷、銳利）。
- 遺物 53 件（普通／稀有／傳說／詛咒／王座），面板類直接加在能力值面板；戰鬥類 25 種接上戰鬥事件。
- 事件 16 則（燈塔、瞳孔商人、鏡中倒影、灰燼之靈、巨骸、千臂賭桌、星蝕祭司、救生艙、血月泉、無聲圖書館、鎖魂領主、骨笛手、雙月、停擺的鐘、百鬼夜行、蛾的祭壇、墜落星圖），各有立繪與 2～3 個選擇。
- 選秀 6 選 3；戰利品：賽爾豆、星晶、遺物三選一、精靈契約三選一；星爐：修復／復甦／淬鍊（永久 +8%）；祭壇：血／蝕／暗三契。
