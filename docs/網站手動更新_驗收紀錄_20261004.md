## 之後更新（不消耗 AI token）

1. 將已測試修改推到 GitHub。
2. 網站控制中心 → 檢查更新 → 前往 GitHub 建置／發布。
3. 選 **Build website package without AI → Run workflow**。不勾 publish 只驗證，勾選才發布。
4. 工作流程成功後，玩家按「檢查網站更新」，再套用新版；不要在戰鬥或編輯中途重載。

GitHub 可能使用帳號的建置／儲存額度，但流程不呼叫 AI。更新玩家頁面與發布網站伺服器是兩件事。
