## 四、預設性格

未設定性格時改為「提升種族值最高的一項」：降低項為較弱的那一項攻擊（與預設學習力「本攻＋體力」一致），若最高項本身是攻擊則降另一攻擊。同分優先本攻 → 速度 → 防禦 → 特防。
例：帝辛 固執、奧佩婭 保守、速度最高的特攻手 膽小、防禦最高的特攻手 大膽。
新建精靈、圖鑑預設、隊伍／詳情顯示一併套用；已存檔且明確存了平衡性格的自訂精靈不改動。

## 五、技能傷害不明顯（待你選）

現況：紅字在頂部狀態卡旁的小膠囊（text-2xl、約 0.5 秒），與精靈立繪距離遠。可選方案：

1. 紅字改到**受擊方立繪正中**，放大到 4～5 rem、描邊＋彈跳，停留約 1 秒。
2. 立繪受擊時**閃白＋震動**，並在 HP 條上保留「剛扣掉的那段」（殘影條）約 1 秒再縮回。
3. 每次出手後中央顯示一行**行動摘要**「技能名 → 1234（克制×2／暴擊）」，在戰鬥資訊列也保留最後一筆。
4. 動畫設定新增「傷害數字大小／停留時間」選項。

建議 1＋2（最直觀），3 作為補充。
