## 百分比傷害校正

整理時已在原站的描述與執行路徑成對修正；JSON 和程式摘錄使用修正後的版本。

| 技能 | 取值基準 | 文字 | 程式類別與免疫 |
| --- | --- | --- | --- |
| 剛莖棍壓 | 自身最大體力 20% | 百分比傷害；未造成時轉真實傷害 | `percentDamage`，檢查 `percentDamageImmune`，原有真傷 fallback |
| 日月安屬 | 本次被抵擋的攻擊傷害 100% | 反擊百分比傷害 | `percentDamage`，檢查攻擊者的 `percentDamageImmune` |
| 恆·蒼穹斗轉 | 自身最大體力 25% | 百分比傷害；免疫時轉真實傷害 | `percentDamage`，免疫判斷改為 `percentDamageImmune` |

不能只搜尋同一整句的 `%` 或 `1/3` 就替換「固定傷害」：例如「陰陽三合」的 **20% 機率附加 100 點固定傷害**是機率與定額；「敕赦千銘」的 **固定傷害提升 30%**是倍率；「赤龍」累計攻擊傷害並以最大體力 100% 為**上限**，實際附加量仍是已抵擋的點數。這些維持原類別。`1/2`、`1/3` 若描述吸取／回血，亦不可改成傷害。

## 接入主專案的實際工作

1. 將 JSON 的 `spa/spd` 對應 `spatk/spdef`，屬性 `遠古+戰鬥` 等映射至現有雙屬性格式；精靈須有穩定 ID、圖像與目前 `Elf` 所需欄位。先避免原站 0 種族值的無為龍者被一般能力計算器當作普通精靈處理。
2. 依每隻精靈建立獨立 `src/effects/*Registry.ts`；透過 `BattleEventContext`、`SoulMarkRegistry`、`BattleSkillRegistry` 接入。不要複製單頁版 `hit`、`dealDamage` 或把精靈特例加進 `BattleScreen.tsx`。
3. 先處理共用事件：開戰／場下／登場、技能前、命中與受傷、回合起訖、換位、PP／封印、護盾／護罩、印記、額外執行。再逐隻移植技能與魂印；描述要與實際可執行效果同步。
4. 此專案的 `createDamageEntry({unit:'percent'})` 預設以**目標最大體力**取值；上表三招分別使用自身最大體力或當次攻擊傷害，必須先算出點數，再按百分比傷害類別結算與檢查免疫。不能直接把 `20`、`25`、`100` 傳成目標體力百分比。
5. 原站「真神之神・聖靈譜尼」只有兩個技能，其他三招在取得正規設計前不可宣稱完整。所有六隻都需對照本專案既有同名／相關精靈、測試魂印多時點效果及換位後狀態生命週期。

本次只將**來源資料和實裝參考碼**加入倉庫；尚未把六隻精靈放進可選隊伍，以免顯示完整敘述卻在戰鬥時缺失效果。
