本批接續共同機制修復。先核對目前程式與 TXT，再集中修正減傷入口與缺少的機制，最後執行驗證。不把 handler 存在、描述可解析或日誌出現算作效果正確。本地混合工作樹中其他 AI 的修改保留；本批未提交或推送。

## 執行計畫與實際結果

| 步驟 | 問題 | 本批處理 |
|---|---|---|
| 1 | 99% 特例只接部分入口，可能連攻擊者輸出下降一起改掉 | 新增共用減傷政策；普通攻擊、X 系技能、額外行動、固定及百分比 API 共用。只改持有者實際觸發的「受到傷害降低」 |
| 2 | 減傷分類與方向不一致 | 分開造成傷害降低／受到傷害降低，明確攻擊、技能、非真實、固定／百分比範圍；真實傷害不吃普通減傷 |
| 3 | 多個減傷直接相加，製造原文沒有的完全免傷 | 不同來源對剩餘傷害乘算；明確同來源才加算原比例，再套特殊比例。保留有明確 100% 的效果，不因兜底變回 1 |
| 4 | 腐朽、千秋一淚未涵蓋全部對應入口 | 腐朽令持有者的攻擊傷害减傷比例失效，但不抹掉攻擊者自己的輸出下降；千秋一淚每兩層使技能傷害減傷比例乘 0.5，按持有者過濾 |
| 5 | 特質、異常、套裝與印記各有一套減傷 | 統一入口與方向；守護印記只減攻擊傷害，投石者四技能石的攻擊增減傷接入正式引擎；一次防護只在符合分類時消耗 |
| 6 | 門檻拿未增傷的 base 判斷；反應發生於主傷害之前 | 新增終段判定及結算回饋回呼；增減伤、固定點數減免就緒後才選門檻分支，傷害後才執行汲取等反應 |
| 7 | 精靈缺碼或是假代替效果 | 補柯爾霍德高／低傷分支、柯爾德減傷後反應、帝辛誅魔天陣與忽略減傷；移除混沌布萊克原文沒有的低血完全免傷 |
| 8 | 技能石的使用時減半文字被拆句後漏掉 | 修文字 fallback 的使用時前綴，以及積木中的概率減傷與分類／次數判定 |
| 9 | 自身技能輸出上限被對手防護貫穿一起略過 | 黯痕上限為持有者輸出限制，與對手傷害上限分開；有相應無視條件時改技能傷害降低 50%，不是無條件取消 |
| 10 | 修改後清單與程式不一致 | 重新產生官方實裝核對 JSON／MD，並加入新語意與實際對戰測試至完整測試鏈 |

## 本批明確的減傷規則

- 攻擊傷害是技能傷害的子類；X 系與額外行動也是技能傷害，但不等於攻擊傷害。
- 吸取固定點數是固定傷害，吸取比例是百分比傷害；汲取是真實傷害。恢復量用結算值，不限制為實際 HP 扣除量。
- 99% 特例不能在沒有減傷效果時憑空產生減傷；不改固定點數減免、雙防值、抵擋、護盾或傷害上限。
- 明確的固定點數減免在比例乘區後扣除，最低為 0。
- 不同來源各 50% 剩下 25%，不是相加成 100%；明確同來源的 20%＋30% 才是 50%。同來源在 99% 特例下仍為 99%，不會加成 198%。
- 無視「對手減傷」只令其減傷比例無效，不會取消攻擊者自己的輸出下降，也不會自动貫穿技能無效、傷害抵擋、盾罩或存活條件。
- 本批未改連擊公式與動畫：連擊仍為一次結算、一次動畫；不改成逐擊，也不混用額外行動。

### 原文交互作用的暫定解讀

1. 同時有「比例變 99%」及「減傷效果衰減／失效」時，先將實際觸發的減傷比例改成 99%，再乘衰減倍率。例如兩道千秋一淚為 49.5%；腐朽的攻擊傷害減傷為 0%。已用測試固定，不宣稱原文已明說優先順序。
2. 柯爾德「不高於 200」與「不低於 200」照字面在恰好 200 時兩者皆符合，不擅自改成互斥。
3. 誅魔天陣目前採個體保留、下場時不作用於下一隻；回合計數隨在場魂印暫停。場下是否仍應倒數未獲額外確認，保留為待核對事項。

| 滄嵐 | 魂印技能傷害減半涵蓋攻擊、X 系、額外行動；固定／百分比的護盾分段減半走共用政策 |
| 次元龍 | 詩章及一次技能減傷依技能類別套用；非技能傷害不消耗一次技能減傷，也不誤算成輸出增傷 |
| 馬爾修斯 | 盾與罩必須同時存在，才觸發一次非真傷減半；真傷不消耗該次數 |

| 柯爾德「冰」 | 非真傷減 60%；依該減傷實際減少量決定反噬／凍傷分支。無視减傷或減少量為 0 時不誤觸發副作用；反噬改在戰鬥階段結束，不是回合結束 |
| 帝辛誅魔天陣 | 九道八荒開 9 回合天陣；受到非真傷扣除對手已損失體力點數。對手每次受傷記錄傷害前體力快照，恢復／體力調整／直接更新不能超過有效快照，但不改 maxHp；來源結束或换人時限制失效。正常關閉體力調整至 1、PP 清零、下回合鎖切；九鼎鎖定期間擊敗對手可提前關閉 |
| 帝怒傾天 | 三道八荒且固有效果有效時，無視對手的比例減傷；不順便無視其他種類防護 |
| 混沌布萊克 | 移除不在原文的低體力完全免傷與相伴的先制 +3 假機制；其餘舊魂印不能因此標記完成 |
| 投石者／黯痕 | 四技能石包括 -S、-SS 正式名稱；攻擊傷害增減 50% 接主流程。黯痕輸出限制及無視條件接所有技能傷害分支 |
