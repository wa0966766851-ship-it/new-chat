## 使用者驗收

重新整理 localhost，按喇叭或「控制中心 → 音樂 → 播放」。播放器可直接操作；被阻擋時按影片內播放鍵。若顯示播放中但仍沒聲音，確認影片與瀏覽器分頁是否靜音及 Windows 音量混音器；若出現錯誤，回報畫面上的代碼與使用歌曲。

官方依據：

- [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)：就緒、播放狀態、自動播放阻擋及錯誤事件。
- [YouTube Required Minimum Functionality](https://developers.google.com/youtube/terms/required-minimum-functionality)：播放器尺寸、可見性與控制項要求。此次瀏覽器驗收的影片區域為 318×200，未覆蓋原生控制項。

## 同日續查：Edge 應用程式模式仍無聲（已確認原因）

上文是前一輪紀錄；「影片時間前進、未靜音」不能證明 Windows／喇叭有聲。本輪針對使用者真正使用的 Edge 應用程式模式再查：

1. 實際 localhost 預設曲為 `wJ8onQryXRY`，影片時間前進、`paused=false`、`muted=false`、`readyState=4`，沒有播放器錯誤。
2. 使用 Windows Core Audio 唯讀檢查：輸出装置音量 30% 且未靜音，但 Edge 音訊工作階段為 **音量 0%、靜音 true**；仍有解碼後訊號峰值 `0.182720`。這是本輪無聲的直接原因，網頁內取消靜音不能解除 Windows 工作階段靜音。
3. 使用者明確同意將 Edge 系統音量改為 60% 並解除靜音。操作後讀回 **60%、靜音 false**，訊號峰值 `0.409114`；未變更全系統輸出裝置的音量。
4. 使用者回報「音樂有播放了，應該是沒問題了」，並自行關閉多餘畫面。本輪停止開啟驗收頁，不再打擾。
