# 視角迷霧（隱匿／魘昧）與第三輪修正（2026-10-03）

驗證：`npm run lint`、`npm test`（新增 tests/viewerFog.semantic.test.ts）、`npm run build` 全過。

## 一、隱匿（戰場迷霧）

新增 `src/battle/viewerPerspective.ts`：本地對戰以 P1 為己方視角；`hiddenFromViewer(elf, side)` 只在**敵方**隱匿時為真，己方隱匿精靈完整顯示。

敵方隱匿精靈在畫面上：
- 名稱「未知精靈」、頭像／立繪鬼影、不顯示屬性圖標；詳情不可開啟（己方可開）。
- 能力等級、防護、異常、印記、計時效果整區改為「未知效果」。
- 屬性克制倍率（精靈卡與上方對陣條）顯示「未知／×?」。
- 所有文字（對戰信息、最後一筆訊息、浮字標籤、出招名稱、傷害統計）中，該精靈的名稱→未知精靈、技能→未知技能、魂印與特質名稱→未知效果。
- 出招日誌只對敵方顯示「未知精靈使用了未知技能」，己方照常。

限制：文字掩蓋依名稱比對；若效果文字裡用其他稱呼描述該精靈的機制，仍可能露出。

## 二、魘昧

- 官方圖標（SeerAPI 異常 44）補進 `public/seer/abnormal/44.png`；原本因「魘昧／魘味」別名方向寫反，圖標一直找不到。
- 正式名稱改用「魘昧」（「魘味」保留為舊字形別名），分類為弱化類＋**限制類**。
- 迷霧程度依官方「場上的異常狀態、能力提升狀態對己方均展示為 1 回合的魘昧」：
  - 己方持有魘昧時，雙方場上精靈的異常狀態一律顯示為「魘昧(1)」。
  - 能力**提升**顯示為「魘昧(1)」；能力**下降**照常顯示（原本連下降也一起遮）。
  - 對戰信息裡【異常名稱】改顯示【魘昧】。
  - 只改顯示，不改實際效果與回合數。

## 三、其他修正

- 砥礪觸發不再移除異常（照戰鬥百科）。
- 雷伊：雷神（雙攻／雙防 +已損體力%，最高 70%）與電氣纏繞（對手最終攻擊／特攻＝面板原始值 70%）改為傷害公式中的**能力值**，不再用增減傷倍率代替。
- 聖怒方向、洗禮頌保底翻倍、但願 4 倍克制與先制上限、告命詩途技能傷害、英雄之耀 3 層 PP：見《新精靈描述標記與名詞確認》。
