# 首頁打包警告與按需載入修正

日期：2026-10-03。基準提交：d56c200。這輪僅修改載入、打包與回歸驗證，不修改技能數值；「靈光之怒」依使用者要求保留現行公式。

## 根因

實際超標的是首頁入口 `index-wRdgEJD8.js`（525,154 bytes），不是 Blockly。首頁靜態引入尚未開啟的控制中心設定、學習力／性格、抗性、克制與刻印調校面板，因此啟動就需要載入這些程式。單純調高警告門檻或把同樣的初始依賴移到另一個靜態區塊，不會減少初始載入量。

大型區塊警告不代表建置失敗，也不能單憑它斷言戰鬥卡頓。本次降低實際載入量，沒有提高 Vite 警告門檻。

## 修改檔案與做法

- `src/components/StartScreen.tsx`：詳情調校面板改為按需載入，各自提供載入狀態；刻印彈窗等待期間可取消。
- `src/components/ControlHub.tsx`：保留常駐主題、播放器、事件訂閱與狀態，僅延後設定視窗；開關視窗不重置分類或輪替歌單。
- 新增 `src/components/ControlHubPanel.tsx`、`ControlHubPresets.ts`：分離設定視窗與共用純設定資料，不新增常駐副作用。
- 新增 `src/components/InscriptionSlot.tsx`、`InscriptionModal.tsx`：拆開輕量刻印孔與調校彈窗，共用六角形外框。
- `src/components/InscriptionSystem.tsx`：保留舊匯入介面的相容再匯出，避免破壞精靈編輯頁與既有測試。
- `tests/homepageLoading.semantic.test.ts`：實際掛載首頁及控制中心，檢查未開啟面板沒有執行、點開才載入、分類／歌單保留，以及刻印 Escape 取消與焦點恢復。
- `scripts/audit_bundle.ts`：主區塊預算 480,000 bytes、首頁靜態依賴總量 950,000 bytes、所有 JS 區塊 500,000 bytes；禁止調校／設定／積木工具提前混入首頁靜態載入圖。這是回歸預算，不是提高建置警告門檻。
- `.github/workflows/ci.yml`：正式建置後執行打包稽核，以前只有建置成功並不會攔下體積回歸。
- `package.json`：互動測試納入完整測試；Electron 建置接入大小稽核與隔離伺服器啟動測試；將僅開發模式使用的 `vite` 排除出 Electron 伺服器包，避免帶入 esbuild／lightningcss 原生開發工具。Electron 主程序既有啟動環境為 `NODE_ENV=production`，開發模式仍使用原本開發指令。
- `tests/electronServerPackaging.semantic.test.mjs`：將正式伺服器與首頁複製到獨立暫存目錄，不提供專案 node_modules、NODE_PATH 或 API 金鑰，驗證啟動、健康 API 與首頁。結束後僅清除經邊界核對的自建測試目錄。

## 實際結果

以下前端大小為未 gzip 的正式產物 bytes／1,000，不是原始碼行數。

| 指標 | 修正前 | 修正後 |
| --- | ---: | ---: |
| 首頁主區塊 | 525.15 kB | 449.04 kB |
| 主區塊 gzip | 129.69 kB | 112.84 kB |
| 首頁靜態 JS 總量 | 1,009.62 kB | 933.51 kB |
| Electron 伺服器包（建置顯示約值） | 7.3 MB | 3.2 MB |

主區塊減少約 14.5%；初始 JS 總量減少約 7.5%。設定視窗 44.13 kB、刻印彈窗 11.07 kB 等改在使用時才載入。`codexRegistry` 仍為 491.25 kB，未超過回歸預算，但成長空間有限，後續擴充需要持續稽核。

- `npm test`：完整串接測試通過，包含新首頁按需載入互動測試及原有戰鬥／特殊模式測試。測試中既有 24678 開發 WebSocket 埠占用提示不影響退出結果；未終止使用者開發伺服器。

- `git diff --check`：通過。

## 尚未驗證與界線

本輪修正的是前端載入與 Electron 建置流程，未重新產生 EXE 安裝程式、未驗收乾淨 Windows 安裝／升級流程，未上傳或推送本輪修改。隔離伺服器測試不能取代完整 Electron 視窗與安裝包驗收。

本輪未量測低階手機 FPS、長任務或長時間記憶體，不宣稱所有裝置絕對不卡頓。圖片／素材總體積、全量技能語意覆蓋、其他頁面布局不計入本次完成範圍。
