# 對戰動畫整理實作與驗收（2026-10-02）

本次依使用者確認的方向，只整理已結算事件的播放，不改技能／魂印效果的計算、判定時機、免疫規則或原本出手順序。

## 播放流程

1. 出招顯示技能名。攻擊招以立繪小幅前移呈現，屬性招以短暫亮光呈現，不再移動整個資訊艙。
2. 技能傷害顯示紅字；實際吃藥的回血即時顯示綠字黃邊。藥劑標記只用於呈現，沒有改變回血邏輯的 isPotion 參數。
3. 額外行動只有真的產生技能傷害紀錄時才播放紅字，不插入固定的空白動畫段。
4. 回合收束播放粉傷（固定／百分比合計）、綠字黃邊回血、白傷。同側同一隻精靈的同類事件合併，完整逐筆事件仍保留在原日誌。多筆白傷顯示總額，不漏掉前面的傷害。
5. 數字短暫停留 520ms、退場預留 160ms，完成後才播放下一筆或開放下一回合。中央重複傷害卡不再顯示。取消暴擊文字的旋轉與劇烈放大，以及不必要的常駐閃爍。

## 結算與顯示的界線

- `BattlePresentation` 保存已結算的呈現紀錄與播放 HP，沒有修改 BattleState 的權限。戰鬥驅動器、效果判定與對外結果快照仍讀取真實狀態。
- 主畫面的 HP 和數字依播放進度更新，其他邏輯不讀播放 HP。播放結束對齊真實 HP；回合編號也在收束完成後才更新。
- 非致命的分組播放不製造假陣亡；遇到致命事件或陣亡判定時，先按原紀錄順序播放待處理事件，再進入原本的換人／勝負流程。沒有讓已被擊倒者繼續出手。
- 換人依實際 battleId／id 對齊新精靈 HP，數字也綁精靈身份，不會顯示在下一隻身上。
- 關閉／重來會清除播放 HP、待播紀錄、數字與尚未完成的等待計時。StrictMode 的模擬重掛不會誤銷毀正在使用的控制器。
- 快速模式保留同樣的結算與數字總量，省略播放等待。

自訂版面同樣使用這套數字播放器，資訊艙保持固定；固定版面則將數字放在立繪上方。原有 7 組未使用 CSS 特效仍未接入。

## 驗收依據

- 新增播放器語意測試：即時紅傷、即時藥劑回血、粉綠白順序、白傷合計、空段跳過、致命事件原序、同側不同身份、卸載取消與重來清除。
- 真實 BattleScreen 整合測試：有／無額外行動的紅字筆數不同；普通播放與快速模式的隊伍 HP、PP、狀態、日誌、註冊狀態、計時器、回合與階段快照一致。
- 在紅傷尚未播放完成時重建戰鬥，等待舊計時到期後確認新局 HP、回合與畫面均無殘留。
- 既有完整測試、型別檢查、正式建置通過；首頁 JS 容量檢查仍為 983.55 kB，動畫模組留在戰鬥區塊。
- 實際 Edge 瀏覽器跑完出招、額外行動與收束，確認回合結束無數字殘留、無頁面錯誤。截圖：
