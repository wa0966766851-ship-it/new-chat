# 魂印與子類的用詞

依使用者2026-10-23明確定義：

- 魂印：所有被動效果的總稱，不能只當專屬特性的別名。
- 專屬特性：魂印下的子類。既有資料欄位 soulMark 承載此類，不因此將所有子類改叫專屬特性。
- 特質：以實際子類標示，例如二代特質、專屬特質；不加「異能」前綴。
- 異能：獨立的效果類別，既有資料欄位 alienTraits.alienTrait。
- 異能精靈：精靈的身分類別；與效果欄位和特質分開，不能僅因有某特質就推定身分。
- 通用特性：可調整配置，既有 trait 與 alienTraits.generalTrait 皆屬此類；不能改稱特質或異能。

介紹頁標題使用「魂印」，各效果標示自己的子類。新精靈介紹/完整介紹模板不列通用特性等配置項；配置與戰鬥檢視仍保留查閱及運作。

禁止創造「異能特質」「異能特性」「通用異能特性」等混稱。原始描述、積木、效果執行與存檔欄位不因顯示用詞修正而改寫。

AI更新時先檢查 src/battle/effectSources.ts 的來源分類與 configurable，再檢查介紹是否用 includeConfigurable:false。以 tests/elfSpotlight.ui.test.tsx 驗證完整戰鬥來源保留、介紹排除配置、分類標籤與身分標記各自正確，不只搜尋畫面文字。
