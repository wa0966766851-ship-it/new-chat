# 技能文義下一輪修復計畫

工作目錄：`D:\影片\新增資料夾\對戰模擬器`。先讀 AGENTS.md、同日《技能文義與替代實裝盤點》MD／JSON及《全精靈效果實裝核對》JSON。沿用既有工作樹，保留前幾輪立繪、普通對戰介面、重來與動畫修復；不能覆寫或回退其他未提交變更。

## 必須遵守的文義

1. effectType:none、處理器存在、註解、積木解析率，都不能證明實際效果是否正确。先讀 SKILL_MODE／SOUL_MODE 和完整事件鏈。
2. 威力不是傷害。含吸取／消強／反轉的威力變化技能，先執行明文能力操作，再從最新狀態計算威力與傷害。使用本輪新增 `*_DAMAGE_TRANSFORMS`／`transformSkillBeforeDamage`；不能移到未命中之前強行消強。
3. 當次條件先制、視強為弱／視弱為強、必中、命中、PP選擇特權為固有；附加失效時保留，固有失效時關閉。命中後掛的下N回合先制等仍是附加，不能混為当次固有。
4. 未觸發／成功／失敗分枝繼承父分類，按對應操作的真实結果觸發。排隊伤害返回值不等於实际HP减少；用结算反馈。
5. 專屬機制放專屬registry，主控制器只能提供通用節點；必須測P1/P2、失效／免疫、下場／同名實例、期限／清除／重來。
