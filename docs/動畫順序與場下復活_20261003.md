# 動畫順序、場下復活、異常預設回合（2026-10-03）

## 名詞
- **技能傷害**：會受屬性克制影響的傷害（攻擊技能、X系技能傷害、額外行動）。紅字，帶克制／微弱／普通／無效，數字為護盾吸收後、剩餘體力截斷前的傷害。

## 播放順序
1. 藥劑：綠字黃框（發生當下）。
2. 出招動畫（等前面的演出播完才開始）。
3. 紅字技能傷害。
4. 額外行動：攻擊方再做一次出招動作，紅字合併一筆，標「額外行動」。
5. 回合結束：
   - 固定／百分比／回血／體力調整，依精靈合併為**體力淨變化**：正→綠字黃框、負→粉字、0 不播。
   - 真實傷害（白字）最後。
- 回合開始等節點若有技能傷害，發生當下播（保留空間，不另外預設位置）。
- 擊倒不再把累積的延後紀錄插到前面；已倒下的精靈不再播後續延後紀錄。
- 直接改體力而沒留紀錄的效果，回合末用「預定體力 vs 實際體力」對帳，差額併入淨變化。

## 場下復活
- 已陣亡的精靈不再響應回合開始／結束節點；例外：其召喚的額外精靈仍存活時（例：斯嘉麗重生由珀妮執行，珀妮不在則重生中斷）。
- 回復效果一律擋陣亡者（含 0 體力存活規則以外的情況）。
- 亂舞不會波及已陣亡的場下精靈。
- 死後倒數期間仍算陣亡，不計入存活；時間到才於背包內重生。隊伍全滅即判負。

## 異常回合
- 未特別定義回合數的異常：預設 3 回合。
- 衍生轉化（漸凍→冰封等）預設 3 回合，其他轉化依各自規則。
- 轉化撞上既有同名異常、或多個異常同時轉化成同一個：合併為一筆，回合數相加。
