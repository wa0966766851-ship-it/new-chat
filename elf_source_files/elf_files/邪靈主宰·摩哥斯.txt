# 邪靈主宰·摩哥斯

種族值：790
攻擊：80 特攻：154 防禦：120 特防：120 速度：142 體力：174
屬性：邪靈

## ◆ 專屬特性/魂印


> 出戰時若己方不存在魂珠則獲得魂珠
>> 擁有/獲得魂珠後從中吸取力量並開始根據魂珠狀態變化執行相應效果
>> 之後自身回合開始時若場上存在技能PP值為0的精靈且同時存在處於狂暴異常狀態的精靈時則當回合開始時重新執行出戰效果

> **自身擁有魂珠時：**
>> 自身所有技能必定命中
>> 敵我雙方任一方使用技能時附加給對手1道埒殘銜闕
>>> 附加成功或對手道數已滿則使用方消耗該技能全部PP值並恢復己方場下體力最低的精靈PP值消耗量×20的體力且該精靈下次出戰時獲得等量臨時體力上限（通過此來源獲得的臨時體力上限最多疊加1次，可與不同來源疊加）
>>> 上述效果觸發同時若對手攜帶技能中識別屬性存在為自身天敵則額外交換雙方克制倍數
>>>> 交換成功後若對手當前克制倍數高於自身時令雙方克制倍數歸1
>>>> 對手每有1道埒殘銜闕時自身克制倍數額外+1(持續到任一方下場)

> **戰鬥階段結束時：**
>> 吸取對手350點固定體力，自身體力低於最大體力½時吸取效果翻倍
>> 恢復體力後每溢出自身最大體力1%則下回合攻擊技能額外附加對手最大體力1%的真實傷害

## ◆ 魂珠狀態

> **魂珠：**
>> 擁有豐腴期、竭擇期與混沌期三種狀態，每次獲得魂珠時初始為豐腴期
>> 每次從魂珠吸取力量時解除己方在場精靈所有異常狀態、恢復全部體力與PP值
>>> 敵我雙方每存活1隻精靈或識別屬性中帶有邪靈系的精靈則額外為在場精靈附加1回合平靜
>> 摩哥斯本場戰鬥中首次於該顆魂珠存在期間死亡時保留自身1點體力，同時將型態轉變為竭擇期
>> 每次從魂珠吸取力量時若敵我雙方在場精靈識別屬性及技能識別屬性中存在混沌系則進入混沌期
>>> 直到本場戰鬥結束時該顆魂珠無法進入竭擇期與觸發保留體力
>> 魂珠下場後保留，上限1顆，狀態保留

> **豐腴期：**
>> 魂珠為豐腴期時每次從魂珠吸取力量的當回合結束時剝奪對方登場效果與技能固有效果
>> 剝奪成功則對手下1回合內無法行動與恢復體力且受到固定傷害、百分比傷害轉化為真實傷害

> **竭擇期：**
>> 魂珠進入該狀態時提升摩哥斯所有能力值25%並驅逐下場
>> 此後己方所有精靈出戰時首次受到的攻擊傷害轉化為等量體力並執行摩哥斯出戰效果，最多執行2次失去魂珠

> **混沌期：**
>> 魂珠每回合開始時將賦予對方在場非神靈系精靈混沌系並取代隨機一種屬性
>>> 賦予識別中帶有聖靈系精靈時有100%觸發湮滅：令對手當回合無法行動與恢復體力並受到238點真實傷害
>>>> 觸發湮滅後對手屬性隨機轉變為虛空系/輪迴系
>> 對方在場精靈為混沌系、神靈系時本次效果執行時該效果失效
>> 在場精靈不處於平靜狀態時每回合開始時令敵我雙方進入狂暴
>>> 任一方未觸發則2回合內對手非真實傷害減半
>>> 進入平靜狀態時解除自身狂暴狀態

## ◆ 相關說明

> **埒殘銜闕：**
>> 持有者每次受到非真實傷害時被埒殘銜闕吸取等同於傷害值的體力50%，每次觸發時每道獨立生效1次
>> 持有者受到非真實傷害提升50%
>> 若傷害不等於技能威力值×(1+n)時則100%令自身進入害怕
>> 若低於技能威力值×(1+n)則自身下次所有技能先制-3且至少降至先制-3
>> 每次被埒殘銜闕吸取體力時若對方在場精靈為邪靈主宰·摩哥斯或自身天敵，則埒殘銜闕吸取的體力額外恢復至對手在場精靈
>> n=埒殘銜闕道數，上限3道，下場後保留

> **驅逐：** 隨機選擇並切換至己方場下的非額外精靈中的存活精靈，主動/死亡切換/登場等相關效果失效

> **技能固有效果：** 包含任何在技能描述中使用技能時即可觸發的效果，且不因技能無效或附加效果失效的任何技能效果（例如先制+n、必中、無視免疫效果、無視能力提升等等）

> **平靜：**
>> 附屬類異常，處於該狀態使用技能時不受PP值限制且不消耗PP值
>> 回合結束時受到最大體力1%的真實傷害（不致死）並恢復自身所有技能一定PP值
>>> 恢復量等於自身PP值上限最高者⅕，向上取整

> **狂暴：** 附屬類異常，處於該狀態造成攻擊傷害翻倍
